# 动态监控三探针

按月运行三个探针，输出《月度资金健康体检报告》。

## 探针 1：资金敞口分析（我现在欠了多少钱？） {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱} {#探针-1资金敞口分析我现在欠了多少钱}

**数据源**：每月累计报审产值（或监理确认产值） vs 每月累计银行转账金额（含各类支付工具）

**计算公式**：
- 累计资金敞口 = 累计确认产值 − 累计已支付金额
- 累计拨付率 = 累计已支付金额 / 累计确认产值

**Agent 判定规则（Skill）**：

1. 异常检测（漏传凭证提示）
   - 如果当月转账凭证金额总和，远小于财务系统/合同台账中记录的"本月计划支付金额"
   - Agent 不直接判定为"没钱"
   - 而是温和提示负责人："本月上传的转账凭证金额（X 万）与计划支付金额（Y 万）存在较大差异，请确认是否漏传凭证，或存在已审批但未实际打款的情况。"

2. 风险定性
   - 拨付率持续下降 → 说明欠款在滚雪球，总包垫资压力剧增
   - 敞口绝对值过大 → 若敞口金额超过合同额的 20%（或超过总包合理垫资极限），Agent 必须提示："当前累计欠款已达 X 万，逼近行业平均垫资极限，总包停工及索赔风险极高。"

## 探针 2：资金流出结构分析（我的钱花得对不对？） {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对} {#探针-2资金流出结构分析我的钱花得对不对}

**数据源**：银行转账凭证（按收款方和用途分类）

**Agent 判定规则（Skill）**：

1. 8 类支出自动分类
   - 总包进度款
   - 分包款
   - 材料设备款
   - 农民工工资专户拨款
   - 管理费/咨询费
   - 还本付息
   - 其他

2. 计算各类支出的占比，并与合同约定或预算计划进行比对

3. 风险定性
   - 结构失衡：如果"农民工工资专户拨款"占比低于法定红线（如 20%），或者"还本付息"占比过高挤压了工程款支付，Agent 必须预警："本月资金流出结构异常，人工费拨付未达标，面临合规风险；同时偿债压力过大，建议调整资金分配优先级。"
   - 异常流出：如果在资金紧张时，仍大额支付"管理费"、"咨询费"等非生产性支出，Agent 提示："资金紧张期，建议严控非生产性支出。"

## 探针 3：未来风险推演（下个月/下季度会不会"断气"？） {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气} {#探针-3未来风险推演下个月下季度会不会断气}

**数据源**：当前资金敞口、历史支付节奏、下月/下季施工计划（或产值计划）、刚性支出计划

**Agent 判定规则（Skill + LLM）**：

1. 推演下月刚性支出
   - 农民工工资：基于实名制系统（如黔薪保）在场人数 × 平均薪资估算，或读取下月工资表
   - 到期债务：读取财务系统的下月还本付息计划
   - 核心主材款：基于下月施工计划（如需要浇筑多少方混凝土），估算必须现金支付的材料款

2. 推演下月预计流入
   - 基于当前的资金筹措方案（如银行下月预计提款额、销售回款预测、财政拨款计划）

3. 计算缺口：下月预计流入 − 下月刚性支出
   - 若为负值，且账面可用现金无法覆盖 → 直接预警

4. 风险定性
   - 短期流动性危机：预测下月将出现 X 万元的刚性缺口，必须提前筹措
   - 趋势性恶化：如果连续 3 个月"资金敞口"都在扩大，且"拨付率"持续走低，Agent 必须给出定性结论："项目资金链呈趋势性恶化，按当前节奏，预计在第 X 个月将面临全面停工风险，建议立即启动债务重组或引入新资金方。"
