### 1.1 命令行跑实测

```bash

python scripts/safety_engine.py --text "<案情文本>" --format md

# 批量跑全部用例（推荐）
python scripts/test_engine.py
```

- ✅ 命中规则 ID 是否正确

## 六、综合压力测试（多风险并发）

### 案例 1：厂房项目·外墙脚手架 + 塔吊无证上岗三项并发隐患（v1.0 原始案例）

**案情**：外墙脚手架高处作业，未设临边防护，脚手架未验收就上人施工，塔吊作业人员无证上岗。

**预期**：
- 命中：B1（临边无防护）+ B3（脚手架未验收）+ B2（塔吊无证）+ B21（起重司机子类）
- 阶段：pre
- 复合规则：无（C1-C5 触发条件未满足）

### 案例 2：10 层模板支撑未验收 + 业主催工期

**案情**：高层住宅 10 层正在浇筑混凝土，模板支撑还没验收，业主催工期，能不能先浇筑再补验收？

**预期**：
- 命中：B8（模板支撑未验收即浇筑）
- 阶段：during（"正在浇筑"）
- 复合规则：若同时含"高处作业"则触发 C3

### 案例 3：无证电工接电（v1.1 真实会话案例）

**案情**：工地缺电工，我有个工人没电工证但干了三年，能让他接临时用电吗？

**预期**：
- 命中：B2（特种作业无证）+ B4（临时用电不规范）+ B18（电工子类无证）
- 阶段：pre

### 案例 4：动火 + 消防不到位 → 重大火灾（C1 触发）

**案情**：动火作业未办动火证，灭火器过期、消防通道堵塞、监护人缺失。

**预期**：
- 命中：B9 + B13 + **C1**
- 阶段：pre

### 案例 5：板房违规 + 工人宿舍 → 重大群死群伤（C4 触发）

**案情**：工人宿舍使用大功率电器做饭、私拉电线、疏散通道堵塞。
