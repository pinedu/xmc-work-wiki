**判定顺序**（v1.2 升级）：
1. **先查否定词**，命中即判属性为 False（避免"没有安装临边防护"里的正向子串"安装临边防护"被误判为 True）
2. **双重否定豁免**：若否定短语出现在"不是没/并非未"等双重否定标记前 → 视为肯定（如"不是没戴安全帽" = 戴了）
3. **否定未命中再查肯定词**，命中判 True
4. 两者都不命中则该属性不出现（规则不因此命中）

## 二、规则 B1–B21（21 条核心规则）

| 规则 | 名称 | 命中条件 | 风险类型 | 基础等级 |
|---|---|---|---|---|
| **B1** | 高空作业 + 无临边防护 | `is_high_altitude=True` 且 `edge_guard_installed=False` | 高处坠落风险 | 按高度：>5m 重大 / 2–5m 较大 |
| **B2** | 特种作业无证上岗（通用） | `is_special_operation=True` 且 `has_special_cert=False` | 安全风险（触电/高处坠落/机械伤害等） | 重大 |
| **B3** | 脚手架未验收即使用 | `uses_scaffold=True` 且 `scaffold_inspected=False` 且 `is_high_altitude=True` | 坍塌 / 高处坠落风险 | 重大 |
| **B4** | 临时用电不规范 | `uses_temp_power=True` 且 `temp_power_design_done=False` | 触电 / 火灾与爆炸风险 | 较大 |
| **B5** | 深基坑 + 降水不到位 | `is_deep_foundation=True` 且 `dewatering_ok=False` | 坍塌风险 | 重大 |
| **B6** | 高处作业 + 未系安全带 | `is_high_altitude=True` 且 `safety_belt_worn=False` | 高处坠落风险 | 按高度：>5m 重大 / 2–5m 较大 |
| **B7** | 未佩戴安全帽 | `helmet_worn=False` | 物体打击风险 | 较大 |
| **B8** | **模板支撑未验收即浇筑** | `uses_formwork_support=True` 且 `formwork_inspected=False` | 坍塌风险 | 重大 |
| **B9** | **动火作业未办动火证/无监护人** | `uses_hot_work=True` 且 `hot_work_permit_done=False` | 火灾与爆炸风险 | 重大 |
| **B10** | **起重吊装未备案或司索信号工无证** | `uses_lifting=True` 且 `lifting_filing_done=False` | 起重伤害风险 | 重大 |
| **B11** | **移动操作平台未验收/无防倾覆** | `uses_mobile_platform=True` 且 `mobile_platform_inspected=False` | 高处坠落 / 倾覆风险 | 较大（涉高处时升重大） |

| **B14** | **卸料平台未验收或超载堆料** | `uses_discharge_platform=True` 且 `discharge_platform_inspected=False` | 高处坠落 / 物体打击风险 | 较大 |
| **B15** | **临建板房消防/用电违规** | `uses_temporary_building=True` 且 `temporary_building_fire_safe=False` | 火灾风险 | 重大（涉人员密集） |

## 三、复合规则 C1–C5（场景叠加判定，v1.2 新增）

> **原理**：现实事故往往是多因素叠加（如"动火+易燃物"火灾概率倍增）。复合规则在单规则全部命中后，再叠加一次更高级的判定与升级建议。

| 复合规则 | 名称 | 联动基础规则 | 风险升级 | 升级说明 |
|---|---|---|---|---|
| **C1** | 动火 + 消防不到位 → 重大火灾 | B9 + B13 | 重大风险 | 动火违规 + 消防不到位 = 火灾事故几乎必然发生；责任从单一违规升级为系统性管理失职 |
| **C2** | 移动平台 + 高处作业 → 重大坠落 | B11 | 重大风险 | 移动平台无防倾覆 + 高处作业 = 倾覆坠落风险极高 |
| **C3** | 模板未验收 + 浇筑混凝土 → 重大坍塌 | B8 | 重大风险 | 高大模板坍塌典型场景；责任升级为系统性管理失职 |
| **C4** | 临建违规 + 人员密集 → 重大群死群伤 | B15 | 重大风险 | 板房违规 + 工人宿舍 = 群死群伤典型场景 |
| **C5** | 起重违规 + 高处作业 → 重大复合伤害 | B10 | 重大风险 | 物体打击 + 起重伤害复合风险 |

## 四、阶段字段 STAGE（v1.2 新增）

引擎自动识别案情所处的阶段，**优先级 post > during > pre**：

| 阶段 | 含义 | 触发关键词 |
|---|---|---|
| `post` | **事后·已发生事故** | 已经发生事故 / 发生安全事故 / 人员伤亡 / 死亡 / 重伤 / 发生坠落/坍塌/触电/火灾/爆炸 / 已造成 / 事故调查 |
| `during` | **事中·违规进行中** | 正在 / 仍在 / 持续作业 / 继续施工 / 未停止作业 / 未停工 / 边施工边 |
| `pre` | **事前·隐患阶段** | 发现隐患 / 存在隐患 / 未验收 / 未配备 / 未办理 / 未设置 / 缺少 / 缺失 / 不符合要求 / 不到位 / 不规范 / 违反规定 / 违规 |
| `unknown` | 未识别（建议人工补判） | 无任何阶段关键词命中 |

**阶段用途**：
- post → 联动 `rhzy-skill4-incident-duty-allocation` 启动事故责任分配 + 三问评估法
- during → 必须用《停工令》（不可用《整改通知单》替代）
- pre → 可用《安全隐患整改通知单》启动整改流程

## 五、处置策略 R-B1–R-B21（21 条策略）

## 六、处置红线（硬约束，5 条）

1. 安全优先：隐患未消除前，不得建议继续施工作业。
2. 不瞒报：生产安全事故须依法按时限报告，不得瞒报 / 迟报 / 隐匿。
3. 责任不可免除：建设单位的安全生产管理 / 报告责任，不得以内部协议免除。
4. 对内对外效力分离：《责任切割协议》仅内部追偿效力，不得对抗从业人员及监管部门。
5. 证据固化优先：现场影像、监控、旁站、验收与整改记录及时封存备查。
