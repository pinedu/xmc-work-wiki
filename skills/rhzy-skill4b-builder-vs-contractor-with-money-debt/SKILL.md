# 建设单位欠总包钱时（位势不足）的处置 SOP

## Overview {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview} {#Overview}

**这是一类被绝大多数"标准质量管理体系"忽略的实战问题**——建设单位欠总包钱，资金紧张，没有位势启动"暂停拨付/违约金扣款/换人换总包"等强对抗手段，但**质量问题必须解决、节点必须推进、不能闹大**。

**核心矛盾**：从"对抗"切换为"绑定"——把"你的死"和"总包的死"绑在一起，让总包自然知道该配合谁。

**这不是"认怂"，是"算账"。**

## When to Use {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use} {#When-to-Use}

**使用**（满足任一即触发）：
- 建设单位欠总包/分包工程款
- 建设单位资金紧张，**没有资金底气**启动强对抗手段
- 之前用过约谈/整改/扣款/换人/发律师函，**总包不响应**
- 没有备选总包/备选班组可换
- 总包"摆烂"反制风险高（你一闹大，总包就反诉你欠款）
- 节点（消防验收/竣工备案/交付）卡在班组质量上，但钱袋子空了
- 决策人想"压一压班组"但发现"压不动"

**不要用于**：
- 班组质量问题但位势充足（用 rhzy-wage-skill3）
- 农民工个人欠薪投诉（用 rhzy-wage-skill1）
- 抢工阶段临时工管理（用 rhzy-wage-skill2）
- 总包企业层面风险评估（用 rhzy-skill1）

### 招数 1：**把"对抗"切换为"算账"**（🔴 最重要，立刻做） {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做} {#招数-1把对抗切换为算账-最重要立刻做}

**操作**：
- 主动约总包**公司分管领导**（不是项目经理，是**公司层级**）
- 主题不是"班组质量"，是"**项目现状和咱们怎么一起活下去**"
- 准备"**双方利益绑定表**"：
  - 你的死：消防验收过不了 = 房子卖不出 = 银行还不上 = 项目公司破产 = 你个人**列入失信 + 7 年禁入**
  - 总包的死：班组质量不达标 = 项目烂尾 = 工程款收不回 = 公司**列入失信 + 集团声誉损失**
  - **共同死法**：项目公司破产 → 总包剩余工程款血本无归 + 你个人进黑名单

**会上的话术（直接用）**：

> "今天不是吵架，是**算账**。
> 
> 我方现状：项目公司资金紧张，**应付贵司的工程款暂时有缺口**——但这不是我方推卸责任，是**项目销售回款节奏问题**。
> 
> 现实压力：消防验收是 8 月底节点——**过不了，我们一起死**——你们拿不到剩余 X% 工程款，我上失信人名单。
> 
> 现在班组质量问题不解决，消防验收过不了，**我们就被锁死**。
> 
> 我的提议：**咱们结成'生死同盟'，一起把消防验收过掉**。
> 
> 具体方案：
> 1. 木工班组**贵司**亲自接手管理，从贵司自有工人里派人**带班 + 帮带**，3 个班组同步推进
> 2. 我方**想办法筹措一笔专项资金**，按节点支付质量奖金，**直接发到工人卡**，**绕过班组**
> 3. 消防验收通过后，**贵司工程款我方做还款计划**，分 3-6 个月分批付清，**附正式承诺函 + 法律担保**
> 4. **双方签一份'消防验收冲刺攻坚专项协议'**——把责任、节点、付款节奏、违约责任**白纸黑字定死**
> 
> 这不是妥协，**这是 1+1>2**。咱们一起把活干完，把钱拿回来，谁都别想摆烂。"

**威力**：
- **把"你欠我、我欠你"的对抗关系** → 变成"咱们一起活下去"的合作关系
- **总包公司领导一听"你我都上失信人"**会重新算账——总包比你会算账
- **正式协议 + 还款承诺** = **总包没有反诉的借口**
