# 建设单位反索赔剧本库（rhzy-counterclaim-playbook）· v1.0

本 skill 解决**"4 类外部主体（总包/监理/设计院/勘察）造成损失后，建设单位如何合法反索赔"**的标准化操作。

## 一、5 类反索赔场景总览

| 场景 | 责任主体 | 主要法律依据 | 主要合同依据 | 主办/协办 |
|---|---|---|---|---|
| **A. 勘察漏判** | 勘察单位（如 111 队） | 《建设工程质量管理条例》第 19、20 条 | 《建设工程勘察合同》GF-2016-0203 第 5.1、14.2.2、15.1 条 | 工程部主办 + 成本部协办 |
| **B. 总包质量缺陷** | 总包 | 《建设工程质量管理条例》第 26、32、64 条 | 《建设工程施工合同》GF-2017-0201 第 5、15、16 条 | 工程部主办 + 成本部协办 |

| **D. 总包工资拖欠** | 总包（第一责任）→ 班组（实际欠薪方） | 《保障农民工工资支付条例》第 26、29、30、33 条 | 《建设工程施工合同》第 15.3 条 + 工资专户管理协议 | 财务部主办 + 工程部 + 综合部协办 |

## 二、A 类反索赔剧本：勘察漏判（云岭中心核心场景）

### 背景

- 云岭中心项目位于贵阳观山湖区，**喀斯特地貌发育**
- 111 地质大队为本项目勘察单位，**通过公开招标入围**（首次合作）
- 基坑北侧开挖至 -18m 揭露**未预报的大型溶洞**，与原勘察报告严重不符

### 责任主体
**贵州省地质矿产勘查开发局 111 地质大队**（合同责任主体）

### 法律依据（**必查原文，必走 rhzy-law-citation-strict**）

> ⚠️ 必查本机 `gz-construction-law-wiki` 是否已落档：
> - 《建设工程质量管理条例》（国务院令第 279 号）
> - 《建设工程勘察合同》示范文本 GF-2016-0203

**4 件套引用模板**：

```
🔗 《建设工程质量管理条例》（国务院令第 279 号）

> 第十九条 勘察、设计单位必须按照工程建设强制性标准进行勘察、设计，
> 并对其勘察、设计的质量负责。
> 注册建筑师、注册结构工程师等注册执业人员应当在设计文件上签字，
> 对设计文件负责。
>
> 第二十条 勘察单位提供的地质、测量、水文等勘察成果必须真实、准确。

🔗 《建设工程勘察合同》示范文本（GF-2016-0203）

> 5.1.1 成果质量应符合相关技术标准和深度规定，且满足合同约定的质量要求。
>
> 14.2.2 因勘察人原因造成成果资料质量达不到合同约定的质量标准，
> 勘察人应负责无偿给予补充完善使其达到质量合格。
> 因勘察人原因导致工程质量安全事故或其他事故时，
> 勘察人除负责采取补救措施外，应通过所投工程勘察责任保险向发包人
> 承担赔偿责任或根据直接经济损失程度按专用合同条款约定向发包人支付赔偿金。
>
> 15.1 发包人索赔
> 勘察人未按合同约定履行义务或发生错误以及应由勘察人承担责任的其他情形，
> 造成工期延误及发包人的经济损失，
> 除专用合同条款另有约定外，
> 发包人可按下列程序以书面形式向勘察人索赔：
> （1）违约事件发生后 7 天内，向勘察人发出索赔意向通知；
> （2）发出索赔意向通知后 14 天内，向勘察人提出经济损失的索赔报告及有关资料；
> （3）勘察人在收到发包人送交的索赔报告和有关资料后，于 28 天内给予答复；
> （4）勘察人在收到发包人送交的索赔报告和有关资料后 28 天内未予答复……
> 视为该项索赔已被认可；
```

### 处置 SOP（5 步）

**步骤 1：事实锁定（0-3 天）**
- 收集现场影像、监理签证、专家组论证意见
- 设计院出具《设计变更通知单》确认溶洞处理方案
- 全部资料刻盘归档（**防未来翻供**）

**步骤 2：发送《索赔意向通知》（7 天内）**
- 主办：成本合约部
- 模板核心内容：
  - 事实陈述（溶洞揭露时间/位置/规模）
  - 与原勘察报告的偏差对比
  - 引用 4 件套法条依据
  - 明确告知将提出经济索赔
  - **7 天时限**（依《勘察合同》第 15.1 条）

**步骤 3：发出《索赔报告》（14 天内）**
- 主办：成本合约部
- 内容：
  - 经济损失明细（溶洞处理费 + 工期延误损失 + 专家费 + 监测费等）
  - 引用《质量管理条例》第 19、20 条 + 《勘察合同》第 5.1、14.2.2 条
  - 索赔金额（**第三方造价咨询审计为准**）
  - 14 天时限

**步骤 4：协商或升级（28 天内等答复）**
- 28 天内未答复 = **视为索赔已被认可**（依《勘察合同》第 15.1 条第 4 项）
- 答复不接受 = 走第 16 条争议解决（**仲裁：贵阳仲裁委员会 / 诉讼**）
- ⚠️ 鉴于 111 队为首次合作、公开招标入围，可**双轨施压**：
  - 暂停本项目剩余 30% 勘察费支付
  - 上报**贵州省住建厅**（行业主管部门）
  - 抄送**贵州省地质矿产勘查开发局**（上级主管局）

**步骤 5：闭环 + 联动**
- 反索赔到账 → 冲抵溶洞处理成本（B 方案 200 万溢价 / A 方案额外费用）
- 联动基坑监测体系（**第三方监测 24h 驻场**）—— 防二次溶洞

### 联动点

- 联动 `rhzy-functional-coverage-audit`：事件归属"工程部主办 + 成本部协办"
- 联动 `rhzy-skill2-legal-counsel`：合规预判（4 类触发 → 4 类定性）
- 联动 `rhzy-law-citation-strict`：涉法引用必过 4 件套门

## 三、B 类反索赔剧本：总包质量缺陷

### 背景
总包施工过程中出现质量缺陷（蜂窝麻面、防水破损、混凝土强度不足等）

### 责任主体
**总包单位**（中建四局五公司）

### 法律依据

> ⚠️ 必查 `gz-construction-law-wiki` 是否已落档《建设工程质量管理条例》

**核心条款**：
- 第 26 条：施工单位对建设工程的施工质量负责
- 第 28 条：施工单位必须按照工程设计图纸和施工技术标准施工
- 第 32 条：施工单位对施工中出现质量问题的建设工程……应当负责返修
- 第 64 条：偷工减料 / 使用不合格材料 / 不按图施工 → 罚款 2%-4% 合同价 + 返工 + 赔偿

### 处置 SOP（5 步）

**步骤 1：质量鉴定（0-7 天）**
- 第三方检测单位出具《质量鉴定报告》
- 设计院确认是否影响结构安全
- 监理 + 工程部现场签认

**步骤 2：总包限期整改（7-15 天）**
- 工程部发《质量整改通知单》
- 引用第 32 条 + 合同第 5.4 条
- 明确整改时限 + 不整改的后果

**步骤 3：复验 + 扣款（15-30 天）**
- 整改完成后监理 + 工程部复验
- 不合格 → 启动反索赔
- 合格 → 走质保金扣减（按缺陷程度）

**步骤 4：反索赔计算（30-45 天）**
- 返工费用 + 工期延误损失 + 检测费
- 引用《质量管理条例》第 64 条 + 《施工合同》第 16.2 条
- 套用合同违约金比例

**步骤 5：协商或仲裁（45-60 天）**
- 协商不成 → 仲裁（贵阳仲裁委员会）或诉讼

### 联动点
- 联动 `rhzy-skill3-duty-performance-analysis`：4 类漏洞定性
- 联动 `rhzy-skill4-incident-duty-allocation`：事故责任分配

## 四、C 类反索赔剧本：总包工期延误（含设计变更引起的顺延）

### 背景
总包因各种原因（管理不善/资源不足/工序问题）造成工期延误

### 责任主体
**总包单位**（中建四局五公司）

### 核心区分

| 延误原因 | 责任方 | 处置 |
|---|---|---|
| **设计变更**（设计院/建设单位）| 设计院/建设单位 | **顺延工期**（**不能扣违约金**）|
| **总包自身**（管理/资源/工序）| 总包 | **不顺延 + 反索赔** |
| **不可抗力**（暴雨/疫情/地震）| 双方按比例 | 部分顺延 + 双方分担费用 |
| **建设单位原因**（图纸延误/支付延误）| 建设单位 | **顺延工期 + 窝工费** |

### 法律依据
- 《质量管理条例》第 10 条：建设单位不得任意压缩合理工期
- 《施工合同》第 7.5 条（工期延误）
- 《施工合同》第 10.6 条（变更引起的工期调整）
- 《施工合同》第 11 条（价格调整）
- 《施工合同》第 19 条（索赔程序）

### 处置 SOP（5 步）

**步骤 1：工期事实认定（0-7 天）**
- 调取总包施工日志 + 监理月报 + 形象进度记录
- **关键**：分清延误原因（**设计变更 / 总包自身 / 不可抗力 / 建设单位**）

**步骤 2：分类处置（7-15 天）**
- 设计变更 → 顺延工期（不扣违约金，但**也不能多报**）
- 总包自身 → 不顺延 + 启动反索赔
- 不可抗力 → 部分顺延 + 双方按合同比例分担
- 建设单位原因 → 顺延 + 窝工费（如有）

**步骤 3：反索赔计算（15-30 天）**
- 违约金：按合同约定的"每天 0.5‰-1‰ 合同价"计算
- 实际损失：建设单位另行委托第三方施工的费用
- 联动基坑等关键节点影响

**步骤 4：审批层级（30-45 天）**
| 延误天数 | 审批层级 |
|---|---|
| ≤ 7 天 | 项目负责人 |
| 8-30 天 | 集团分管副总 |
| 31-60 天 | 集团总经理办公会 |
| > 60 天 | 集团董事会 |

**步骤 5：协商或仲裁（45-60 天）**

### 联动点
- 联动 `rhzy-functional-coverage-audit` Pitfall 6：金额/工期 ≠ 主办部门（**永远是成本部主办 + 工程部协办**）

## 五、D 类反索赔剧本：总包工资拖欠

### 背景
总包拖欠农民工工资，**建设单位承担监督责任**（依《工资支付条例》第 29 条）

### 责任主体
**总包（第一责任）→ 班组长（实际欠薪方）**

### 法律依据（**必查原文**）
- 《保障农民工工资支付条例》第 26 条（专户）
- 第 28 条（实名制 + 劳资专管员）
- **第 29 条**（建设单位监督 + 先行垫付）
- **第 30 条**（总包先行清偿）
- 第 33 条（专户资金不可查封冻结）

### 处置 SOP（4 步）

**步骤 1：应急响应（0-4 小时）**
- 综合行政部现场维稳（开门+接待+登记+3 件套）
- 工程部劳资专管员核实考勤
- 财务部核查专户余额
- **4 个绝对红线**：不肢体冲突 / 不当场承诺垫付 / 不让堵门超 4 小时 / 不让部门擅自接受采访

**步骤 2：分类处置（4-72 小时）**
| 情况 | 判定 | 主办 |
|---|---|---|
| A. 误投诉（银行系统延迟）| 🟢 解释 + 出具流水 | 工程部 |
| B. 流程卡壳（未审批）| 🟡 财务部立即审批 | 财务部 |
| C. 总包漏报/克扣| 🔴 总包违规 | 成本部合同追责 |
| D. 总包挪用专户| 🔴 重大违规 | 报警 + 前期部对接住建 |

**步骤 3：先行垫付（如必须，依《条例》第 29 条）**
- 建设单位以**未结清工程款为限**先行垫付
- 必须**领导决策**（白名单无此职能）
- 走应急资金通道（**不挪专户**）

**步骤 4：追偿（依《条例》第 30 条）**
- 总包拖欠 → 建设单位垫付后向**总包追偿**
- 分包拖欠 → 总包**先行清偿**，再向分包追偿
- 涉嫌刑事 → 移送公安（**项目负责人审批 + 法务/合规配合执行**）

### 联动点
- 联动 `rhzy-wage-skill1-government-complaint-handling`：政府投诉应对
- 联动 `rhzy-wage-skill4-subcontractor-wage-recovery`：劳务老板欠薪追偿
- 联动 `rhzy-wage-skill5-wage-anomaly-detection`：工资异常核查

## 六、E 类反索赔剧本：设计错图

### 背景
设计院图纸存在错漏（尺寸错误/节点构造错误/与规范冲突），导致预埋件位置错误、返工等

### 责任主体
**设计院**（贵州省建筑设计院）

### 法律依据
- 《建设工程质量管理条例》第 19 条（按强制性标准）
- 第 21 条（设计必须根据勘察成果）
- 第 22 条（材料设备规格）
- 第 24 条（设计事故责任）

### 处置 SOP（4 步）

**步骤 1：发起变更联络单（0-3 天）**
- 工程部出具《设计变更联络单》
- **不直接改图**（建设单位无设计资质，**改图 = 越权 + 自背锅**）
- 设计院收到后出具《设计变更通知单》+ 加盖出图章

**步骤 2：核算返工费用（3-15 天）**
- 成本部核算：原图返工费用 - 新图造价
- 引用第 19 条 + 合同质量条款

**步骤 3：发《设计质量索赔函》（15-30 天）**
- 主办：成本部
- 内容：错漏位置 + 返工费用 + 设计合同条款引用

**步骤 4：协商或行业上报（30-60 天）**
- 协商不成 → 仲裁/诉讼
- 严重错图 → 上报**贵州省住建厅**

### 联动点
- 联动 `rhzy-functional-coverage-audit` Pitfall 31：设计院图纸错漏，建设单位**改图 = 越权 + 自背锅**

## 七、F 类反索赔剧本：监理失职

### 背景
监理未按时提交月报/现场签证不规范/与施工方串通

### 责任主体
**监理单位**（贵州三维监理）

### 法律依据
- 《建设工程质量管理条例》第 36-38 条
- **第 67 条**（监理与建设/施工单位串通 → 罚款 50-100 万 + 降低资质 + 连带赔偿）

### 处置 SOP（5 步）

**步骤 1：发《监理工作催办函》**
- 引用《监理规范》+ 监理合同
- 明确未按时提交的法律后果

**步骤 2：内部留底**
- 影像 + 快递底单刻盘归档

**步骤 3：暂停监理费**
- 累计 3 次未按时提交 → 暂停当月监理费

**步骤 4：约谈监理单位法人**
- 工程部主办 + 项目负责人主持

**步骤 5：升级（必要时）**
- 上报**贵阳市住建局**（监理不良行为记录）
- 启动**监理更换程序**（公开招标新监理）
- 涉嫌串通 → 引用第 67 条 + 报警

### 联动点
- 联动 `rhzy-functional-coverage-audit` Pitfall 32：监理失职，建设单位**代写 = 替监理背锅**

## 八、6 类反索赔通用原则

1. **4 件套不可缺**：责任主体 + 法律依据 + 合同依据 + 处置 SOP
2. **先发《索赔意向通知》再发《索赔报告》**：严格依《施工合同》第 19.1 条 / 《勘察合同》第 15.1 条的 7/14/28 天时限
3. **金额核算必走第三方审计**：避免主观争议
4. **审批层级看金额**（联动 `rhzy-functional-coverage-audit` Pitfall 6）：
   - ≤ 8 万：项目负责人
   - 8-200 万：集团分管副总
   - 200 万-1000 万：集团总经理办公会
