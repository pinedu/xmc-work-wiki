# 贵州本地法规速查清单

> 配合主 SKILL.md 使用。本文件列出在贵州省内处理建设工程事故时**优先适用**的本地法规。

---

## 一、贵州省级法规（必查）

### 1. 《贵州省安全生产条例》

- **施行时间**：2017 年（最新修订待查）
- **核心要点**：
  - 建设工程各方安全责任划分
  - 事故报告与处置程序
  - 隐患排查治理制度
  - 安全生产标准化建设
- **适用场景**：本省境内所有建设工程项目
- **查询路径**：贵州省人大常委会官网 / 北大法宝

### 2. 《贵州省建筑市场管理条例》

- **核心要点**：
  - 建设工程招投标管理
  - 转包 / 违法分包 / 挂靠认定
  - 合同管理
  - 工程款支付监管
- **适用场景**：招投标阶段 + 合同履行 + 欠款纠纷

### 3. 《贵州省建设工程施工现场管理规定》

- **核心要点**：
  - 现场封闭管理
  - 人员出入管控
  - 安全警示标志
  - 临时设施管理
  - 消防管理
- **适用场景**：现场日常管理 + 人员闯入致损事件

### 4. 《贵州省人民政府关于进一步加强建筑市场监管的通知》

- **核心要点**：资质管理、信用评价、联合惩戒
- **适用场景**：施工总包资质审核

---

## 二、贵阳市法规（地市级·项目所在地）

### 1. 《贵阳市安全生产条例》（如已制定）

- **适用层级**：贵阳市行政区域内

### 2. 《贵阳市建设工地管理办法》

- **核心要点**：
  - 工地围挡标准
  - 出入口管理
  - 渣土运输
  - 夜间施工管理

### 3. 《贵阳市工程建设项目审批事项清单 5.0 版（试行）》（38 项）

- **核心要点**：
  - 立项用地规划许可
  - 工程建设许可
  - 竣工验收
- **适用场景**：报建阶段合规性核查

## 三、国务院条例 + 部委规章（兜底适用）

| 法规 | 核心条款 | 适用场景 |
|---|---|---|
| 《建设工程安全生产管理条例》 | 第 21 条（总包主体责任） / 第 24 条（建设单位义务） | 责任分配 |
| 《保障农民工工资支付条例》 | 总包代发、实名制、工资保证金 | 欠薪事件 |
| 《工伤保险条例》 | 第 14-15 条（工伤认定） / 第 62 条（用人单位责任） | 工人受伤 |
| 《建筑施工企业安全生产许可证管理规定》 | 许可证有效期、暂扣、吊销 | 资质审核 |
| 《建筑工程施工发包与承包违法行为认定查处管理办法》 | 转包 / 违法分包 / 挂靠认定 | 合同合规 |

## 五、引用法规时的优先顺序

1. **第一优先**：贵州省级地方性法规（针对本省实际制定）
2. **第二优先**：贵阳市地方法规（项目所在地）
3. **第三优先**：国务院条例（行业通用）
4. **第四优先**：部委规章（部门细化）
5. **第五优先**：国家法律（民法典 / 刑法 / 民事诉讼法）

📌 **法律冲突时的处理**：
- 同一事项，**地方法规严于国家法**的，按地方法规
- 同一事项，**地方法规宽于国家法**的，按国家法
- **不冲突**的，并引
