## 第一问：资质审核底档

### 核查清单

| 序号 | 核查项 | 数据源 | 缺失后果 |
|---|---|---|---|
| 1.1 | 营业执照（统一社会信用代码、法人、注册资本） | 国家企业信用信息公示系统 | 主体不明 |
| 1.2 | 资质等级（总包/专业承包/劳务资质） | 住建部四库一平台 | 不能承揽对应工程 |
| 1.3 | **安全生产许可证**（剩余有效期 ≥ 6 个月） | 住建部四库一平台 | **一票否决**（见 skill1） |
| 1.4 | 法人代表身份证、简历 | 投标文件 | 关联风险 |
| 1.5 | 近 3 年类似工程业绩 | 投标文件 + 实地考察 | 履约能力 |
| 1.6 | 财务报表（注册资本实缴、资产负债率） | 投标文件 | 财务健康 |
| 1.7 | 信用中国查询（失信、行政处罚、重大税收违法） | 信用中国 / 国家企业信用信息公示系统 | **一票否决**（见 skill1） |

### 判定标准展开

| 缺失情形 | 评估 | 后续动作 |
|---|---|---|
| 1.1-1.7 全部齐全 | ✅ 资质审核义务**完全履行** | 维持现状 |
| 缺失 1-2 项非关键文件（如 1.4 简历、1.6 财务报表） | ⚠️ 存在**程序瑕疵** | 1 周内补函件调取 / 要求补充 |
| 缺失**关键资质**（1.2 / 1.3） | ❌ **重大程序违法** | **立即停用该单位 + 启动备选 + 内部追责** |
| 安全生产许可证剩余有效期 < 2 个月 | 🚨 **一票否决** | 禁止使用（详见 skill1 红线表） |
| 已列入失信被执行人 / 重大税收违法 | 🚨 **一票否决** | 禁止使用 + 报告纪检 |

## 第二问：事发前整改通知书

### 核查清单

| 序号 | 核查项 | 留档要求 |
|---|---|---|
| 2.1 | 整改通知书原件 | 纸质原件 / 电子签章件 |
| 2.2 | 送达回执（含签收人、签收日期） | 总包项目部签字盖章 |
| 2.3 | 整改前 / 中 / 后照片 | 同一参照物 + 时间戳 |
| 2.4 | 整改完成确认书 | 总包签字 + 监理签字 |
| 2.5 | 整改进度跟踪表 | 项目部归档 |

### 整改通知书的"有效"标准

✅ **有效**：
- 书面（不限于纸质，电子邮件 + 签收回执也可）
- 明确隐患类型 + 整改要求 + 整改时限
- 总包项目部签收（签字 + 日期 + 加盖项目部章）
- 有整改前后对比证据

❌ **无效**：
- 口头通知（无书面记录）
- 微信 / 短信通知（无签收回执）
- 整改后未跟踪、未确认
- 整改书未明确隐患类型

### 与本次事故相关的"整改记录"如何判定

| 整改书内容 | 与事故关联度 | 评估 |
|---|---|---|
| 包含"人员出入管控""门禁管理""考勤管理" | **强相关** | ✅ 督促到位 |
| 包含"现场封闭管理""安全警示" | **中等相关** | ✅ 基本到位 |
| 包含"机械设备""用电安全" | **弱相关** | ⚠️ 仅一般督促 |
| **未发过任何整改书** | **零关联** | ❌ 重大过失 |

### 整改通知书的撰写模板（强建议）

```markdown
# 安全隐患整改通知书

**发函单位**：[建设单位全称]
**收函单位**：[施工总承包单位全称] 项目部
**发函日期**：YYYY-MM-DD
**编号**：XX整字〔YYYY〕第 X 号

## 一、隐患描述

经我方 X 年 X 月 X 日现场检查，发现以下安全隐患：

1. [隐患 1 描述，含具体位置]
2. [隐患 2 描述，含具体位置]
   ...

## 二、整改要求

请贵司项目部于 X 年 X 月 X 日前完成以下整改：

1. [整改 1：含具体动作 + 完成标准]
2. [整改 2：含具体动作 + 完成标准]
   ...

## 三、整改回执

请贵司项目部收到本通知后** 3 个工作日内** 签收回执，整改完成后** 5 个工作日内** 提交《整改完成确认书》（含整改前后对比照片 + 监理签字）。

## 四、违约责任

依据《建设工程施工合同》第 X 条第 X 款约定，逾期未整改或整改不到位的，我方将**暂停相应工程款支付**，并按合同约定**主张违约金 XX 元 / 日**。

[建设单位公章]
[日期]

---

**签收回执**

[总包项目部签字]：_______________
[签收日期]：YYYY-MM-DD
[项目部章]：_______________
```

📌 **关键细节**：
- **必须**有"签收回执"——这是法律上"已送达"的唯一证据
- **必须**有整改时限 + 违约责任——这是法律上"督促到位"的证据
- **不要**用微信 / 短信发——容易被反咬"未正式通知"

## 第三问：工程款拖欠

### 核查清单

| 序号 | 核查项 | 数据源 |
|---|---|---|
| 3.1 | 合同金额（签约价 / 变更后金额） | 施工合同 + 变更签证 |
| 3.2 | 累计已付金额 | 财务凭证 |
| 3.3 | 应付未付金额（按合同进度） | 进度款审核表 |
| 3.4 | 累计延付天数 | 财务系统 |
| 3.5 | 延付是否有合理事由 | 内部审批 + 书面通知 |
| 3.6 | 是否存在以欠款转移管理责任的迹象 | 会议纪要 / 邮件 |

### 工程款支付状态的"四档"判定

| 档位 | 累计延付天数 | 评估 | 法律风险 |
|---|---|---|---|
| **一档**：按合同进度全额支付 | 0 天 | ✅ 不存在以欠款转嫁责任 | 无 |
| **二档**：局部延付但有合理事由 + 已书面通知 | < 60 天 | ⚠️ 建议核查延付理由的合规性 | 较低 |
| **三档**：严重延付 | 60-90 天 | ❌ 存在转移管理责任的嫌疑 | 较高 |
| **四档**：累计延付 > 3 个月 / 无理由延付 | > 90 天 | ❌ 重大法律风险 | 高 |

### 工程款拖欠的反向法律影响

⚠️ **关键警示**：
- 若总包以"甲方拖欠工程款 → 我无钱整改 → 无人值守"为抗辩
- 法院会**反过来**认为：拖欠工程款**事实上转移了安全管理责任**
- 责任比例可能从"督促不到位"上升到"实际管理者"
- **法律建议**：拖欠必须**有书面通知 + 合理事由 + 留下总包未整改证据**——形成"我已通知 + 是他没做"的证据链

## 三问综合判定的实务案例

### 案例 1：完美档（三项齐全）

- 总包资质齐全、安全生产许可证有效期内
- 事发前发过 3 次整改通知书，含"人员出入管控"
- 工程款按合同进度全额支付

**结论**：建设单位**基本无责**，主体责任在总包 / 劳务派遣公司。

### 案例 2：一般档（缺失 1 项）

- 总包资质齐全
- **事发前从未发过任何整改书**
- 工程款按合同进度支付

**结论**：建设单位**有督促不到位过失**——**2 个工作日内补发《整改督促函》+ 留档**。

### 案例 3：重大档（缺失 2 项）

- 总包资质**有瑕疵**（安全生产许可证 1.5 个月后到期）
- **事发前从未发过任何整改书**
- 工程款累计延付 2 个月

**结论**：建设单位**督促责任重大过失**——**立即组建应急小组 + 法务全面介入 + 准备可能比例分担**。

### 案例 4：违法档（3 项全缺失）

- 总包**无相应资质**承揽
- **事发前从未发过任何整改书**
- **严重拖欠工程款 6 个月**

**结论**：建设单位**程序违法**——可能被认定"实际管理者"——**全面档案补建 + 准备抗辩**。
