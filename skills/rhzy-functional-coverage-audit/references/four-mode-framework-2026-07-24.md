## 二、四模式处理逻辑详解

### 事前模式（避坑）

**目标**：识别潜在风险，优化决策

**处理步骤**：
1. 审查事项（合同/变更/付款/选商等）
2. 扫描风险点（价款/工期/质量/责任分配）
3. 匹配同类踩坑案例
4. 输出：风险清单 + 修改建议 + 谈判要点 + 必做事项清单

**典型场景**：
- 准备签订合同
- 准备选商
- 准备变更
- 准备付款
- 准备分包

**主办/协办**：成本部主办 / 工程部协办

---

### 事中模式（止损）

**目标**：发现隐患、纠正偏差、固定证据

**处理步骤**：
1. 诊断隐患性质和严重程度
2. 评估时效风险（索赔期/除斥期间等）
3. 生成紧急行动清单
4. 输出：纠偏方案 + 证据固定指引 + 时限提醒 + 补救文书模板

**典型场景**：
- 已开工但现场异常
- 已签订但程序瑕疵
- 已付款但手续不齐
- 已发生未构成违规的小隐患

**主办/协办**：工程部主办 / 成本部协办

---

### 事后模式（担责+止损）

**目标**：最小化损失、争取最优结果

**处理步骤**：
1. 评估损失规模和责任比例
2. 生成多路径解决方案（协商/索赔/解除/诉讼）
3. 每条路径标注：成本/时间/结果预期/风险
4. 输出：解决路径图 + 谈判/诉讼策略 + 任务跟踪清单

**典型场景**：
- 发生安全事故
- 发生农民工欠薪
- 发生质量事故
- 发生超概算
- 发生行政处罚

**主办/协办**：工程部主办 / 成本部/财务部协办

---

### 割离模式（自证+划界+追责+转嫁）

**目标**：证明无责、划清边界、追真正责任方、转嫁损失

**处理步骤**：
1. **清白自证**：梳理甲方合规行为，生成证据链
2. **边界划定**：明确法律关系，生成对外口径
3. **责任追溯**：逐层找到真正责任方，生成举报/追责材料
4. **损失转嫁**：保险理赔/合同抵扣/代付保护/舆论自保
5. 输出：法律关系图 + 责任矩阵 + 话术指引 + 函件模板 + 行动清单

**典型场景**：
- 红线外市政塌陷（向市政追责）
- 设计院图纸错图（向设计院追责）
- 监理失职（向监理追责）
- 总包违规（向总包追责）
- 政府不当检查（向上级/纪检反映）

**主办/协办**：工程部主办 / 成本部协办

## 三、8 项通用输出详解

任何模式下，输出必须包含：

### 1. 事件定性（一句话）

> 一句话概括事件的性质、当前阶段、关键方。

**示例**：
- "本项目桩基阶段发现大量溶洞，处理费用增加 300 万，事件已发生且反索赔程序未启动。"
- "本项目施工噪声引发居民投诉并升级到街道办+环保局，事件已发生且政府已介入。"

### 2. 风险等级（高/中/低）

| 等级 | 触发条件 |
|---|---|
| 🔴 **高** | 触发红警/触发 ≥10 人群体性/触发刑事责任/触发停工 |
| 🟠 **中** | 触发橙警/触发政府督办/触发行政处罚/触发审计风险 |
| 🟡 **低** | 触发黄警/触发一般投诉/触发程序瑕疵 |

### 3. 法律关系图

| 主体 | 合同关系 | 法定关系 | 责任性质 |
|---|---|---|---|

### 4. 证据清单

| 证据 | 已有 | 缺失 | 固定方法 |
|---|---|---|---|

### 5. 行动清单

- 🚨 **P0 紧急（24 小时内）**
- 🟡 **P1 短期（48 小时内）**
- 🟢 **P2 中期（1 周内）**

### 6. 文书模板

| 文书 | 用途 | 主办 |
|---|---|---|---|

### 7. 对外话术

| 对象 | 话术要点 |
|---|---|

### 8. 跟踪节点

| 节点 | 时限 | 触发条件 |
|---|---|---|

```
1. <立即动作>
2. <协调动作>
3. <禁止动作>
[ 一键生成《<单据>》 ]   [ <后续动作> ]   [ 标记为已知悉，暂不处理 ]

```

### 紧约束清单（必记）

1. ❌ **禁止**输出"判断逻辑"开场白
2. ❌ **禁止**列出"联动信息"
3. ❌ **禁止**输出"模式定位表"
4. ❌ **禁止**长篇分析
5. ❌ **禁止**先讲法律关系图 + 证据清单
6. ✅ **必须**用 🚨 标题开头 + 6 字段结构
7. ✅ **必须**在 📊 字段直接给出"事实 + 卡点 + 影响"
8. ✅ **必须**在 ⚖️ 字段给具体法条编号 + 量化后果
9. ✅ **必须**在 🎯 字段给"做什么 + 否则会怎样"
10. ✅ **必须**底部带 [ 一键生成《单据》] 按钮组

## 五、实战案例集（本会话）

### 案例 1：施工噪声 → 居民投诉 → 街道办+环保局介入

**模式判定**：
- 判断 1：建设单位做了吗？✅ 做了（已开工）
- 判断 2：麻烦产生了吗？✅ 产生了（投诉已升级）
- 判断 3：建设单位有过错吗？❌ 待定

**匹配模式**：**事中模式（止损）** + **割离模式（自证+划界+追责+转嫁）** 双轨

**🚨 警报输出**（本会话实际输出）：
```
🚨 【居民投诉应急处置】居民投诉→街道办+环保局介入
📍 涉及项目：盐务街电信小区三标
⏱️ 发现时间：2026-07-24（投诉已升级到政府）
📊 漏洞定性与管理影响（What & Why）：
本项目施工噪声引发居民投诉，已升级到街道办和环保局，行政介入已启动。
- 总包：噪声源、施工作业 = 第一责任
- 监理：现场监督，未及时发现和制止 = 监督责任
- 甲方：建设活动组织者，负监督管理责任
⚖️ 合规风险量化（Risk）：
🔴 行政处罚：《噪声污染防治法》赋予环保部门 30 天内决定是否处罚
🟠 居民索赔：持续可能升级为群体性投诉或媒体曝光
🟡 合同追责：可依《施工合同》向总包追偿 + 扣违约金
🟡 政府投资审计：群体性投诉可能影响项目审计和考核
🎯 建议管理动作（Action）：
1. P0 24 小时内：综合行政部对接街道办+环保局；工程部+监理全面排查...
2. P1 48 小时内：成本部对总包发《噪声控制整改通知》；总包编制《专项整改方案》...
3. P2 1 周内：工程部组织居民代表现场参观降噪措施...
[ 一键生成《噪声控制整改通知》 ]   [ 一键生成《致街道办/环保局回复函》 ]   [ 一键生成《对总包违约金扣款通知》 ]   [ 标记为已知悉，暂不处理 ]
```
