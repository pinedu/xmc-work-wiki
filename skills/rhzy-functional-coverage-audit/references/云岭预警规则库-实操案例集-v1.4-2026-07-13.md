## 二、v1.4 9 条铁律（执行口诀）

| 铁律 | 一句话 | 反例 | 正例 |
|---|---|---|---|
| **A 绝不调级** | 规则触发即定级，不加修正 | 成本部超 7 天→橙警（加修正） | 成本部超 7 天→红警 |
| **B 区分判定建议** | 判定字段=已发生；建议字段=未来动作 | 4/15 未触发+今日支付避免黄警 | 4/15 不触发 + 独立"处置建议" |
| **C 缺失信息处理** | 输出"⚠️ 缺失信息"+当前判定，不推回 | 老板需确认此前黄警？ | ⚠️ 缺失信息:历史预警 + 当前橙警 |
| **D 处置建议直写** | 写"做什么+否则会怎样"，不"拍板" | 老板需拍板 3 件事 | 今日内完成拨付,否则 27 日橙警 |
| **E 法条核对原文** | 引用前必查 4 份原文,无原文=❓ | 引第 29 条凭印象 | 先查 4 份落档原文+引用 |
| **F 严重事实不替代规则** | 整改不力/多次投诉≠红警 | 3 次投诉+督办+整改不力→红警 | 3 次投诉+督办+整改不力→橙警（人数缺失）|
| **G 规则适用边界** | T→F→R→I 逐条核对,看名称不看关键词 | 安全员配备套 R-01 黄警 | 安全员配备=不触发 R 类 |
| **H 规则分类独立判定** | 内容/时间/资金 3 类独立判,不绑定 | I-04 等 T-02 报送日 | I-04 立即黄警 + T-02 待补日期 |
| **I 时间计算** | 截止日次日=超期第 1 天,不存在"临界" | 3/1 判橙警("3/2 起红警") | 3/1 = 红警（超 15 天）|

## 三、24 条预警规则 + 3 类判定速查

### T 类（时间性）—— 必须有日期
| 编号 | 黄 | 橙 | 红 |
|---|---|---|---|
| T-01 方案审批 3 工作日 | 超 1-2 | 超 3-5 | 超 5 |
| T-02 变更/签证 3 工作日 | 超 1-2 | 超 3-5 | 超 5 |
| T-03 进度款 5 工作日 | 超 1-3 | 超 4-7 | 超 7 |
| T-04 隐蔽验收 24h | 超 12h | 超 24h | 超 48h |
| T-05 资料归档 30 自然日 | 超 1-7 | 超 8-14 | **超 14** |
| T-06 工资拨付 | 超 1 天 | 超 2 天 | 超 3 天 |
| T-07 索赔响应 7 工作日 | 超 1-3 | 超 4-7 | 超 7 |
| T-08 事故报告 1h | 超 1h | 超 3h | （无红警阈值）|

### F 类（资金性）—— 看金额
- F-01 专户 < 50% = 🟡 / F-02 < 30% = 🟠 / F-03 < 10% = 🔴
- F-04 资本金 < 80% = 🟠 / < 50% = 🔴
- F-05 还款日前 5 工作日未备足 = 🟡 / 前 1 工作日 = 🔴

### R 类（内容性）—— 看事实
- R-01 同部位同问题 2 次整改不合格 = 🟡 / 3 次 = 🟠（**质量整改专属**）
- R-02 主体结构安全 = 🔴
- R-03 轻伤事故 = 🟠
- R-04 较大及以上 = 🔴
- R-05 2 次投诉 = 🟡 / 政府督办 = 🟠 / **≥10 人群体性 = 🔴**（v1.1 锁定）

### I 类（内容性）—— 看事实
- I-01 四证不齐全 = 🔴
- I-02 无施工许可证 = 🔴
- I-03 无工资专户 = 🟠
- I-04 签证无影像/无计量 = 🟡（**变更/签证专属**）

### 升级规则
- 同事项同部门连续 2 次黄 → 自动升级 🟠
- 同事项同部门连续 2 次 🟠 → 自动升级 🔴
- 升级时标注"⚠️ 预警升级"

## 四、v1.4 实战判定 4 步法（每题必经）

```
1. 事件复审：复述事件 + 提取关键事实
2. 三类分类：内容性（看有没有）/ 时间性（看日期）/ 资金性（看金额）
3. 逐条核对：T→F→R→I 顺序 + 看名称不看关键词 + 不适用直接跳过
4. 独立判定 + 叠加：每规则独立触发,完成后叠加;缺信息标 ⚠️ 不允许等
```

```

【责任部门】：XX（具体部门名）
【触发规则】：T-XX / F-XX / R-XX / I-XX（如多规则叠加：T-XX+I-XX）
【⚠️ 缺失信息】（如有）：[XX部门]此前是否已触发同类黄/橙警,无法确认自动升级条件是否满足,请补充说明后继续
【处置建议】：（直接写"做什么+否则会怎样",不推回老板）
```

## 六、5 个最常踩坑场景（v1.4 沉淀）

### 场景 1：成本部变更/签证审核超期 → 必然 A 铁律
- **老板原话**："为什么调成橙警？"
- **正确**：超 5 天 = 红警（不加修正）
- **错误**：加"工程部按时""现场未影响"下调

### 场景 2：政府督办 + 多次投诉 + 整改不力 → 必然 F 铁律
- **老板原话**："R-05 红警=仅 ≥10 人"
- **正确**：🟠 橙警（人数缺失=禁止红警）
- **错误**：🔴 红警（用严重事实替代规则条件）

### 场景 3：总包安全员配备不足 → 必然 G 铁律
- **老板原话**："R-01 是质量整改专属"
- **正确**：不触发 R 类（管理动作+合同追责）
- **错误**：🟡 黄警（套用 R-01）

### 场景 4：变更/签证无影像 + 无台班 → 必然 H 铁律
- **老板原话**："I-04 和 T-02 应该分开判断"
- **正确**：I-04 立即 🟡 黄警 + T-02 待补日期
- **错误**：❓ 需补信息（I-04 等 T-02）

### 场景 5：竣工资料归档超 30 自然日 → 必然 I 铁律
- **老板原话**："3/1 已是红警不是临界"
- **正确**：2/14 截止,3/1 = 超 15 天 = 🔴 红警
- **错误**：🟠 橙警（"3/2 起红警"）
