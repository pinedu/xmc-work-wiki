## 一、4 条特殊规则原文

### 1. 施工前许可
> 施工前**必须取得**文物保护部门（贵阳市文旅局 / 文物局）的许可文件。

**触发条件**：项目进入"施工阶段"且涉及任何开挖/桩基/基坑/主体施工动作前。

**判定**：
- 🔴 红警：未取得文保许可即开始施工 = 触发 I-02（无证施工）+ 文保合规双红警。
- 🟢 安全：已取得文保许可且在有效期内。

### 2. 施工中意外发现文物
> 施工过程中**如发现文物，必须立即停工**并报告文物保护部门。

**触发条件**：现场任何施工作业面（基坑/桩孔/沟槽/管沟）出现疑似文物迹象。

**处置硬约束**：
- 第 1 动作 = **立即停工**（不停工 = 重大违法）
- 第 2 动作 = **报告贵阳市文旅局 / 文物局**（口头 24 小时内 + 书面 3 个工作日内）
- 配合义务：保护现场、不得移动 / 哄抢 / 私自处置
- 复工条件：取得文保部门书面复工意见前**不得复工**

**判定**：
- 🔴 红警：发现文物但未立即停工 / 未报告 = 触发 R-02 主体结构安全（类比适用）+ 文保合规双红警。
- 🟡 黄警：已停工已报告但未及时取得复工意见，工期开始受压。

### 3. 文保法规约束
> 文保范围内的施工活动可能受《文物保护法》等法规约束，涉及施工方案审批、现场施工、验收等环节均有特殊规定。

**触发条件**：本项目任何事项涉及以下任一环节：
- 施工方案审批（含专项方案、危大方案）
- 现场施工（含夜间施工、特殊工艺、振动/爆破/打桩）
- 验收（隐蔽验收、分部分项验收、竣工验收）

**判定原则**（铁律 14 配套）：
- 涉及《文物保护法》条款引用，**必须有已落档原文**。
- 无原文 = "❓ 缺原文，未引用"，**绝不凭印象补条款编号**。
- 通用预警规则库的 T-01~T-06 时限，**在本项目中文保事项相关环节不适用**——文保事项必须按文保部门单独要求的时限执行。

### 4. AI 主动提醒义务
> AI 在判定本项目相关事项时，**若涉及文物保护相关审批或许可，优先提醒客户确认文物保护手续是否齐全**。

**触发条件**：本项目（毓秀路）任何事项判定输出中，关键词命中以下任一：
- 文物 / 文保 / 保护范围 / 建设控制地带
- 考古 / 勘探 / 试掘
- 文物局 / 文旅局
- 不可移动文物 / 文物保护单位
- 历史建筑 / 风貌保护 / 历史文化街区

**AI 必做动作**（固化进触发逻辑）：
- 判定输出末尾**强制追加 1 段"文保手续确认提醒"**
- 提醒模板：
  > ⚠️ **文保手续确认**（毓秀路项目特殊规则 4）：本事项涉及 [具体环节]，请确认文物保护相关审批 / 许可文件是否齐全、有效。未取得或失效前**不得进入下一环节**。

**反模式**（禁止）：
- ❌ 仅输出通用判定不追加文保提醒
- ❌ 提醒里使用"建议确认"等弱表述——必须用"**请确认**"+"**不得**"
- ❌ 涉及文保事项但未识别出本项目锚点（"识别锚点失败"= 立即停判定 + 报老板）
