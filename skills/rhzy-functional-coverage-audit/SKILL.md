## 五、典型 Pitfall（最容易犯的错）

### Pitfall 1-11（v4.4 既有沉淀，详见原文）

### ⭐ Pitfall 12（v2026-07-24 本会话新增·最高频踩坑）：把"时间/能不能/找谁"答成多分支剧本

> **老板原话**：本会话反复纠错 5 次（详见 §十八）。

**反例**：用户问"钱什么时候能付" → 答"3 道闸门 + 卡了怎么办 + 4 选 1 方案 + 老板需拍板 X 件事"。

**正确**：**直接答时间**（T+5 正常 / T+13 红警）+ 前置条件一笔带过。

### ⭐ Pitfall 13（v2026-07-24 新增）：盖章漏前提

> **老板原话**："必须把'盖章'和'前提条件'一起说。"

**反例**：答"找综合行政部"。

**正确**：答"**找综合行政部。前提：工程管理部 + 成本合约部已审核签字。上游没签完 = 综合行政部不得用印。**"

### ⭐ Pitfall 14（v2026-07-24 新增）：配合文保 ≠ 复工许可

> **老板原话**："可以配合拍照，但不等于获得复工许可。"

**反例**：把"配合文保部门工作"误读为"默许可以小范围复工"。

**正确**：配合行为（拍照/取证/说明）✅ / 复工行为（任何施工动作）❌ 严格区分。

### ⭐ Pitfall 15（v2026-07-24 新增）：疑似文物不停工 = 刑事 + 行政双重责任

> **老板原话**：本会话老板多次纠错。

**反例**：被"工期紧/集团要求/看起来不像碎片"诱导继续施工。

**正确**：**疑似文物 = 立即停工**（不分看起来像不像、不分工期紧不紧、不分谁判断）。判断权只在文保部门，工人/项目部/集团/施工方外行判断 = **0 法律效力**。

### ⭐ Pitfall 16（v2026-07-24 新增）：安全事故快报倒查 = R-04 红警

> **老板原话**："打电话来问 = 人家在倒查您报没报。"

**反例**：被"应急局打电话问"误读为"还没到必须报的程度"。

**正确**：**1 小时内快报属地应急局**。"打电话来问"= **政府主动倒查 = R-04 红警**。"还没报"= **瞒报嫌疑 = 加倍严重**。

### 一、四模式判断法（老板自创·本会话沉淀）

```
判断 1：建设单位做了没有？
├── 没做 → 事前模式（避坑）
└── 做了 → 继续判断

判断 2：麻烦产生了没有？
├── 没产生 → 事中模式（止损）
└── 产生了 → 继续判断

判断 3：建设单位有没有过错？
├── 有过错 → 事后模式（担责+止损）
└── 无过错 → 割离模式（自证+划界+追责+转嫁）
```

| 模式 | 触发条件 | 目标 | 输出 |
|---|---|---|---|
| **事前（避坑）** | 建设单位没做 | 识别潜在风险，优化决策 | 风险清单 + 修改建议 + 谈判要点 + 必做事项清单 |
| **事中（止损）** | 做了但麻烦未产生 | 发现隐患、纠正偏差、固定证据 | 纠偏方案 + 证据固定指引 + 时限提醒 + 补救文书模板 |
| **事后（担责+止损）** | 做了且麻烦已产生且有过错 | 最小化损失、争取最优结果 | 解决路径图 + 谈判/诉讼策略 + 任务跟踪清单 |
| **割离（自证+划界+追责+转嫁）** | 做了且麻烦已产生但无过错 | 证明无责、划清边界、追真正责任方、转嫁损失 | 法律关系图 + 责任矩阵 + 话术指引 + 函件模板 + 行动清单 |
