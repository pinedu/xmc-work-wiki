- **县级权限（节选）**：
  - 属地资金出资 / 属地工程建设项目
  - 六城区：工业集聚区内工程建设项目
  - 经开区、高新区、综保区、双龙区：全工业项目及划拨类项目
  - 三县一市：属地工程建设项目

### 工程建设许可阶段 · 关键阈值

- **消防设计审查（住建部第 58 号令第十四条）**：
  - 市级：总建筑面积 > 3000㎡、住宅 > 100m、城市轨道/大型发电变配电
  - 县级：≤ 3000㎡、住宅 ≤ 100m、城市隧道、非易燃易爆工厂仓库
- **施工许可（住建）**：
  - 市级：跨两个及以上区级行政区的市政/房屋工程；省市重点市政项目；轨道交通；50 万㎡以上项目
  - 县级：六城区属地范围内（除市住建审批外）；50 万㎡以下；老旧小区改造/背街小巷/棚改；三县一市属地
- **既有建筑装饰装修施工许可**：3000㎡以上归市级；以下六城区及开发区/三县一市属地
- **取水许可（市级权限触发条件）**：①市级审批/核准/备案且地表水日取水量 ≥ 5000m³；②省管下放及猫跳河贵阳境内、洋水河、鱼梁河、小车河、白岩河、三江河、麦架河干流河段日取水量 ≥ 5000m³；③县（市、区）边界河流
- **节能审查（市/县级分工）**：市级 = 年综合能耗 1000~10000 吨标煤或年电力消费 > 500 万 kWh；县级 = 完成区域能评的区域内、年综合能耗 1000~3000 吨标煤且不在负面清单内的项目，告知承诺制

## ⭐ v1.1 关键业务判断：政府投资 vs 社会投资·6 大核心区别

> **本段为 v1.1 重磅增补**——老板 2026-07-13 会话深度使用，固化为 skill 标配。

| 差别维度 | 政府投资 | 社会投资 |
|---|---|---|
| **立项路径** | 建议书 → 可研 → 初设（3 关） | 备案或核准（1 关） |
| **资金来源** | 财政预算 / 专项债 / 国债 | 自筹 / 开发贷 / 垫资 / 股权融资 |
| **资金监督** | 财政 + 审计 双监督 | 内部财务 + 银行 |
| **施工许可前** | 财政资金落实证明（前置） | 资金证明（内部口径） |
| **验收后** | 必走审计决算 + 资产移交 | 备案即可 |
| **权属** | 移交使用单位/行政事业单位 | 建设单位持有 |

> **关键判断点（rhzy 项目立项时必跑）**：项目资金构成 / 是否政府投/社会投 → 决定立项路径走建议书/可研/初设还是备案/核准；决定是否触发财政评审 + 跟踪审计。
