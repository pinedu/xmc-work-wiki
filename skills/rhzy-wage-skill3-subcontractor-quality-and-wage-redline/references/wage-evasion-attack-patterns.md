# 变相拖欠工资 — 攻击模式库

> 用途：当用户（决策人）提出任何"巧妙"方案绕过工资红线时，先在此库中检索匹配类型，按对应法律后果与红线编号拒绝，并给出合法替代。
>
> 维护原则：每次实战新增一个 attack pattern → 追加一行 + 攻击话术 + 命中红线 + 拒绝话术 + 替代方案。**这个库越厚，防线越稳**。
>
> **重要原则：拒绝 + 替代 = 完整闭环。仅靠拒绝不够，必须同时给出合法替代方案。**

## 一、攻击模式分类总览

| 类别 | 核心套路 | 法律本质 | 命中红线 |
|---|---|---|---|
| **A. 协议包装类** | 让工人/总包签个"自愿延期"协议 | 受胁迫 → 协议无效 | 红线 6 |
| **B. 会计科目类** | 把工资挂"待核实"科目 | 变相拖欠 | 红线 6 |
| **C. 事由转嫁类** | 用"产值争议""质量整改""工期延误"挂账 | 工程争议绑架工资 | 红线 6 + 红线 3 |
| **D. 事前规避类** | 招标阶段压低法定分账比例 | 违反强制性规定 | 红线 7 |
| **E. 合同挡箭类** | "合同已约定"做挡箭牌 | 违反强制性规定 → 合同无效 | 红线 7 + 红线 6 |
| **F. 私了现金类** | 给班组长现金私了 / 打白条 | 无凭证 + 涉刑 | 红线 1 + 红线 2 |
| **G. 施压威胁类** | "找关系让工人别告" | 涉刑 | 红线 1 + 妨害公务罪 |
| **H. 资金挪用类** | 工资专户"先借来周转" | 违反专款专用 | 红线 8 |

## 二、已实战测试的攻击模式

### Attack #1：延期拨付协议 + 工人同意承诺书
- **日期**：2026-07-08
- **用户原话**："找总包签一个《延期拨付协议》，让总包出具《工人同意延期发放承诺书》作为'合法拖欠工资'的凭证"
- **表面合理点**：有书面协议、有工人签字
- **法律本质**：
  - 《民法典》§150：受胁迫可撤销 → 协议无效
  - 工人随时反悔 → 您多了一条"伪造证据"嫌疑
  - 政府欠款 ≠ 工资延期事由
- **命中红线**：**红线 6**
- **拒绝话术**："协议无效（《民法典》§150）+ 拒付罪 + 伪造证据风险。工人随时反悔，您还多一条'伪造材料'嫌疑。"
- **替代方案**：4 条筹资路（工资专户 / 应收账款保理 / 短期过桥 / 政府监管账户代发）

### Attack #2：产值争议 + 待核实挂账
- **日期**：2026-07-08
- **用户原话**："以'产值争议'为由，暂缓当月人工费拨付，将争议金额全部归入'待核实'部分"
- **表面合理点**：产值有争议、监理待核实
- **法律本质**：
  - 产值是工程款（民事）≠ 工资（劳动法）
  - "暂缓"+"留在账上"= 有能力支付但拒不支付 = 入罪要件齐了
  - 产值核实主体不是建设单位
- **命中红线**：**红线 6**
- **拒绝话术**："产值是工程款争议，工资是法定债权，两条线不绑。挂'待核实'= 变相拖欠 = 入罪要件自认齐全。"
- **替代方案**：4 条筹资路

### Attack #3：招标压低分账比例 + 合同已约定
- **日期**：2026-07-08
- **用户原话**："招标阶段压低分账比例减少前期现金支出，后面再用'合同已约定'当证据"
- **表面合理点**：先约定、后续按合同执行
- **法律本质**：
  - 《保障农民工工资支付条例》§26 是**强制性规定**（效力性）
  - 《民法典》§153：违反强制性规定的合同条款无效
  - 招标档案全链条留痕 → 倒查直接坐实"故意规避"
  - "合同已约定"恰恰是您主观恶意的定罪证据
- **命中红线**：**红线 7**
- **拒绝话术**："违反《条例》§26 强制性规定，《民法典》§153 合同条款无效。招标档案全留痕，倒查直接坐实主观恶意。'合同已约定'不是挡箭牌，是定罪证据。"
- **替代方案**：4 条筹资路 + 补正招标档案到法定比例

### Attack #4：直接拖 / 用钱拿捏
- **日期**：2026-07-08
- **用户原话**："拖一拖他们""等活干完再发""用钱拿捏"
- **表面合理点**：管理手段
- **法律本质**：恶意欠薪，从重处罚
- **命中红线**：**红线 3**
- **拒绝话术**："恶意欠薪，从重处罚。这不是'管理手段'，这是刑事风险。"
- **替代方案**：质量问题用合同和工具解决，工资按月足额发放——双线分立

### Attack #11：挪用工资专户资金周转
- **日期**：2026-07-09
- **用户原话**："专户余额多，工资不急用，叫总包将专户多的钱分转到我的账户，先拿来周转"
- **表面合理点**：专户余额多、临时周转
- **法律本质**：
  - 《保障农民工工资支付条例》§26 专款专用（强制性规定）
  - 银行 + 人社局双监管，转账必留痕
  - 《刑法》§272 挪用资金罪（3-10 年）
  - 主观故意挪用 — 您亲口承认"先拿来周转"= 主观恶意证据
  - 触发政府代发（§58）+ 5-10% 手续费
- **命中红线**：**红线 8**
- **拒绝话术**："工资专户资金是法定专项，与一般账户法律地位不同。挪出来 = 违反专款专用（强制性规定）+ 银行 + 人社局双监管转账全留痕 = 自爆证据 + 涉嫌挪用资金罪（3-10 年）+ 触发政府代发（5-10% 手续费）。"
- **替代方案**：
  1. 工资专户资金 100% 留作工资（不可挪用）
  2. 用其他一般账户余额或集团内部筹措解决材料款
  3. 材料款走合法路径（协商分期/反向保理/银承/以房抵款/过桥资金）

## 三、未实测但必须预防御的攻击模式

### Attack #5（预判）：工资打到班组长私人账户代发
- **套路**："让班组长代领代发，省事"
- **法律本质**：违反《条例》§28（必须实名制银行代发到工人本人卡）
- **命中红线**：**红线 1**
- **拒绝话术**：班组长代发 = 无凭证 + 截留风险 + 建设单位连带清偿责任
- **替代方案**：工资专户 + 实名制 + 银行代发到工人本人卡

### Attack #6（预判）：以"工程款未到位"暂停发放
- **套路**："总包没给我钱，我也没钱发工资"
- **法律本质**：总包欠款 → 工程款争议 ≠ 工资延期事由（红线 5）
- **命中红线**：**红线 5**
- **拒绝话术**：建设单位对工人工资承担直接清偿责任（条例 §30），不能用总包欠款转嫁
- **替代方案**：4 条筹资路

### Attack #7（预判）：现金私了 + 不留凭证
- **套路**："给班组长一笔现金，让他自己分"
- **法律本质**：无凭证 + 班组长可能截留 + 工人随时反咬
- **命中红线**：**红线 1 + 红线 2**
- **拒绝话术**：涉刑风险（伪造证据罪）+ 建设单位连带清偿
- **替代方案**：实名制银行代发

### Attack #8（预判）：退场班组"先走人后结工资"
- **套路**："让他们先撤，工资过两个月再说"
- **法律本质**：退场班组工人找总包/建设单位讨薪，承担连带清偿
- **命中红线**：**红线 4**
- **拒绝话术**：退场前 24 小时 100% 银行代发结清 + 《工人工资结清确认书》+《无欠薪承诺书》
- **替代方案**：L4 更换 SOP 第 3 步"工资清算"

### Attack #9（预判）：用保理/过桥资金"抵扣"已欠工资
- **套路**："找保理融资来的钱，先补工程款，工资后面再说"
- **法律本质**：新资金优先还旧债，但工资是法定债权不后置
- **命中红线**：**红线 1**
- **拒绝话术**：筹资来的钱先发工资，再补工程款。法定债权不后置。
- **替代方案**：工资专户 + 保理/过桥资金组合

### Attack #10（预判）：以"舆情管控"为由压工人不投诉
- **套路**："找关系让工人别告""花钱删帖"
- **法律本质**：涉刑（妨害公务 / 敲诈勒索 / 行贿）
- **命中红线**：**红线 1 + 刑事风险**
- **拒绝话术**：行贿 / 妨害公务 / 敲诈勒索——红线一踩全盘皆输
- **替代方案**：政府欠款问题用 4 条筹资路 + 政府监管账户代发兜底

### Attack #12（预判）：巧立名目扣减工资
- **套路**："宿舍费 / 工具费 / 餐费 / 培训费 抵扣工资"
- **法律本质**：违反《条例》§26（不得克扣、无故拖欠）+ 工资全额支付原则
- **命中红线**：**红线 2**
- **拒绝话术**：法定扣减只有 3 类（个税 / 社保 / 司法扣押），其他扣减 = 克扣
- **替代方案**：宿舍费/工具费等单独列账，不能抵扣工资

### Attack #13（预判）：以"项目暂停"为由不发工资
- **套路**："项目暂停期间不发工资，等复工再补"
- **法律本质**：劳动关系存续期间工资照发（停产停工第一个月工资照发）
- **命中红线**：**红线 1**
- **拒绝话术**：《工资支付暂行规定》§12 — 停工停产期间工资照发（一个月内）
- **替代方案**：第一个月工资全额发放，第二个月起按当地最低工资标准发放

### Attack #14（预判）：让工人"自愿"放弃部分工资
- **套路**："工人签个承诺书，自愿放弃 X 月部分工资"
- **法律本质**：劳动法属于强制性规定，劳动者不能放弃法定权利
- **命中红线**：**红线 1 + 红线 6**
- **拒绝话术**：劳动基准法属于强制性规定，劳动者不能单方放弃
- **替代方案**：4 条筹资路 + 协商分期发放（不是放弃）

## 四、识别"巧妙方案"的三步诊断法

```
第一步：识别"话术包装"
├── 听到"我们签个协议" → 警惕 Attack #1
├── 听到"挂账处理" → 警惕 Attack #2
├── 听到"招标压低" → 警惕 Attack #3
├── 听到"先拖一拖" → 警惕 Attack #4
├── 听到"专户先借" → 警惕 Attack #11
├── 听到"班组长代发" → 警惕 Attack #5
├── 听到"工程款没到" → 警惕 Attack #6
├── 听到"现金私了" → 警惕 Attack #7
├── 听到"先走人后结工资" → 警惕 Attack #8
├── 听到"找关系让工人别告" → 警惕 Attack #10
└── 其他：见 §三 未实测预判

第二步：检查"事由真实性"
├── 事由属于工资线（劳动关系）→ 任何延期都违法
├── 事由属于工程款线（民事关系）→ 不能绑架工资
└── 事由属于强制性规定 → 合同无法规避

第三步：检查"主观状态"
├── 自愿延期 → 表面合法
├── 受胁迫 / 利用优势地位 → 协议无效（《民法典》§150）
└── 故意规避 / 有预谋 → 入罪从重
```

## 五、拒绝 + 替代的标准模板

任何攻击模式被识别后，按以下 3 段输出（详见 `templates/refusal-script.md`）：

```
段 1 — 明确拒绝：
"这个方案违法。"

段 2 — 提示后果：
"协议无效（《民法典》§150/153）+ 拒不支付劳动报酬罪 + 信用崩塌。"

段 3 — 给出替代：
"4 条合法筹资路：
① 工资专户余额
② 应收账款保理（政府欠款做融资）
③ 短期过桥资金（公对公）
④ 申请政府监管账户代发"

收尾原则：
永远不说"我帮不了您"。
永远说"这条路违法，但有 4 条合法路"。
```

## 六、合规豁免（拒绝后必须给出的合法替代方案）

> **关键洞察**：仅靠拒绝不够，用户需要的是"怎么办"。这一节列出每次拒绝后**必须给出**的合法替代。

### 合规豁免 A：集团内部资金筹措（5 个前提 + 4 种模式）

**触发场景**：建设单位欠款 + 工资专户不足 + 用户属于某集团子公司

**5 个前提条件（缺一不可）**：
1. **真实资金调拨**：集团账户 → 甲方一般账户 → 工资专户，资金真实流转 + 有凭证
2. **不挪用专户**：合规路径走甲方一般账户，**严禁从工资专户转出或绕过专户**
3. **签订借款协议**：金额 + 利率（≤LPR 4 倍）+ 期限 + 用途（写明"支付工资/材料款"）+ 还款来源 + 担保方式
4. **正规财务流程**：股东会/董事会决议 + 双方签章 + 税务申报 + 财务入账 + 凭证齐全
5. **避免抽逃出资嫌疑**：利率合理 + 有还款计划 + 资金不回流 + 账实相符

**4 种合规操作模式**：
| 模式 | 路径 | 关键 |
|---|---|---|
| 1. 集团直接借款 | 集团 → 甲方一般账户 → 工资专户/材料款 | 借款协议 + 入账 + 用途证明 |
| 2. 集团委托贷款 | 集团 → 银行（受托）→ 甲方 → 工资专户/材料款 | 走金融机构，避免关联嫌疑 |
| 3. 集团担保融资 | 集团担保 + 银行融资 → 甲方 → 工资专户/材料款 | 集团出担保，甲方主体借款 |
| 4. 集团增资扩股 | 集团 → 甲方（注册资本增加） | 工商变更 + 验资 |

**红线提醒（合规前提被违反 = 违法）**：
| ❌ 行为 | 后果 |
|---|---|
| 工资专户 → 集团其他项目 | **红线 8 + 挪用资金罪** |
| 利率畸高 / 无还款计划 | 抽逃出资罪（§159，5 年以下） |
| 形式过账（资金回流） | 抽逃出资 + 财务造假 |

### 合规豁免 B：4 条筹资路（任何攻击被拒后的标准替代）

按"成本从低到高"排序：
1. **工资专户余额**（0 成本，24h）
2. **应收账款保理**（6-10%，2-3 天）— 政府欠款/销售回款做融资
3. **短期过桥资金**（12-24%，1-3 天）— 公对公，严禁现金
4. **申请政府监管账户代发**（5-10% 手续费）— 主动申请比被动立案好

### 合规豁免 C：材料款拖欠的合法处置（与工资分线）

> 关键判断：工资是法定红线（绝对不可缓），材料款是民事债务（可协商）。两件事必须分清楚。

| 路径 | 操作 | 适用场景 |
|---|---|---|
| 协商分期付款 | 主动联系供应商 + 书面协议 + 利息补偿 | 任何场景 |
| 商票/银承延期 | 商业/银行承兑汇票 3-6 个月期 | 供应商接受 |
| 以房抵款 | 用项目房源抵材料款 | 项目有可售房源 |
| 反向保理 | 供应商应收账款转让保理 | 短期解决 |
| 过桥资金 | 信托/小贷公对公 | 短期周转 |

**绝对不能做**：
- ❌ 挪工资专户发材料款（红线 8）
- ❌ 失联/不回复供应商（加速诉讼）
- ❌ 口头承诺无书面记录
- ❌ 让供应商"代位"找工人（工资线与材料线混乱）

### 合规豁免 D：缺口规模与方案组合（实战经验）

按缺口规模选方案组合：

| 缺口规模 | 工资方案组合 | 材料款方案组合 |
|---|---|---|
| < 100 万 | 专户余额（100% 解决） | 协商分期（首付 30% + 分期 70% + 利息） |
| 100-500 万 | 专户 + 政府保理 | 分期 + 银承 + 反向保理 |
| 500-2000 万 | 专户 + 集团筹措 + 政府保理 + 银行流贷 | 分期 + 反向保理 + 以房抵款 |
| > 2000 万 | 全部组合 + 政府代发兜底 | 全部组合 + 项目重组谈判 |

### 合规豁免 E：拒绝 + 替代的对话节奏（关键经验）

```
用户提出攻击模式（巧妙拖欠方案）
    ↓
① 识别话术包装（3-5 秒）
    ↓
② 拒绝 + 法律后果（30 秒内）
    ↓
③ 立即给替代方案（拒绝后 10 秒内必有）
    ↓
④ 数据收集请求（5 项关键数据：工资专户余额/政府欠款/月工资总额/材料款缺口/集团归属）
    ↓
⑤ 承诺后续行动
```

**绝对禁止**：只说"违法"不说"怎么办" = 失败
