# 变相拖欠工资 — 标准拒绝 + 替代脚本

> 用途：当用户提出任何"巧妙理由"绕过工资红线时，按本模板填充具体内容输出。
>
> 模板结构：3 段 = 拒绝 + 后果 + 替代。
>
> 核心原则：**永远不说"我帮不了您"。永远说"这条路违法，但有 N 条合法路"。**

---

## 模板 A：协议包装类（Attack #1）

### 拒绝
"这个方案违法。"

### 后果
- 协议无效（《民法典》§150 受胁迫可撤销）
- 拒不支付劳动报酬罪（《刑法》§276 之一）3 年以下
- 群体事件加重情节 3-7 年
- 工人随时反悔 → 您多了一条"伪造证据"嫌疑

### 替代
4 条合法筹资路：
1. **工资专户余额** — 法定专款专用，24h 可发
2. **应收账款保理** — 政府欠款做融资，2-3 天到账，成本 6-10%
3. **短期过桥资金** — 信托/小贷（公对公），1-3 天到账，成本 12-24%
4. **申请政府监管账户代发** — 主动申请比被动立案好（《条例》§58），成本 5-10%

### 收尾
"我们马上启动筹资方案，工期不能停，您也不用冒刑事风险。"

## 模板 B：会计科目类 / 事由转嫁类（Attack #2）

### 拒绝
"挂账/待核实/产值争议 = 变相拖欠 = 违法。"

### 后果
- 工程款争议（民事）≠ 工资延期事由（劳动法）— 两条线不能绑
- "留在账上"+"暂缓"= 有能力支付但拒不支付 = 入罪要件齐了
- 产值核实主体不是建设单位

### 替代
同上模板 A 的 4 条合法路。

### 收尾
"产值是您和总包的事，工资是您和工人的事。两个法律关系，绝不能捆绑。"

---

## 模板 C：合同规避类（Attack #3）

### 拒绝
"招标阶段压低分账比例 = 故意规避 = 违法。"

### 后果
- 违反《保障农民工工资支付条例》§26 强制性规定
- 《民法典》§153：违反强制性规定的合同条款无效
- 招标档案全留痕 → 倒查直接坐实主观恶意
- "合同已约定" = 您的定罪证据，不是您的挡箭牌
- 拒付罪从重处罚 + 招投标资格限制 1-3 年

### 替代
同上模板 A 的 4 条合法路。
**额外建议**：补正招标档案，把分账比例调到法定标准。

### 收尾
"招标档案一旦被倒查，您不是'巧妙'，是'自爆'。分账比例压低省的钱，远不够未来刑事风险的损失。"

---

## 模板 D：直接施压类（Attack #4）

### 拒绝
"拖欠/克扣/施压工人 = 恶意欠薪 = 从重处罚。"

### 后果
- 《刑法》§276 之一 + 加重情节（群体事件）
- 列入欠薪黑名单 1-3 年
- 列入失信被执行人
- 媒体曝光 + 银行抽贷

### 替代
质量问题用合同和工具解决（参见 SKILL.md 的 L1-L4 + 9 类工具）
工资按月足额发放——双线分立。

### 收尾
"质量问题 = 合同 + 监理 + 整改 + 索赔 + 更换。工资 = 按月足额。两条线彻底分开，您既能让质量得到严肃处理，也能让工人工资一分不差。"

---

## 模板 G：工资专户资金挪用类（Attack #11）

### 拒绝
"挪用工资专户资金 = 违反专款专用 = 涉嫌挪用资金罪。"

### 后果
- 《保障农民工工资支付条例》§26 专款专用（强制性规定）
- 银行 + 人社局双监管，转账必留痕 = 自爆证据
- 《刑法》§272 挪用资金罪（3-10 年）
- 主观故意挪用 = 您亲口承认"先拿来周转"
- 触发政府代发（§58）+ 5-10% 手续费

### 替代
1. **工资专户资金 100% 留作工资**（不可挪用）
2. 用其他一般账户余额或集团内部筹措解决材料款
3. 材料款走合规豁免 C 的合法路径

### 收尾
"工资专户是法定专项账户，与一般账户法律地位不同。挪用 = 自爆证据 + 挪用资金罪。专户的钱一分不动，材料款走其他合法路。"

## 模板 H：合规豁免类（用户主动提出合法路径时）

### 场景 A：集团内部筹措
- **确认前提**：先验证 5 个前提是否满足（特别是"真实资金调拨"+"不挪用专户"）
- **起草协议**：《集团内部借款协议》— 金额/利率（≤LPR 4 倍）/期限/用途（写明"支付工资/材料款"）/还款来源/担保方式
- **完善流程**：股东会决议 + 双方签章 + 税务申报 + 财务入账 + 凭证齐全
- **避免误区**：禁止专户转出、禁止利率畸高、禁止资金回流

### 场景 B：4 条筹资路选择
- 按缺口规模选组合：
  - 小缺口（< 100 万）：专户余额
  - 中缺口（100-500 万）：专户 + 保理
  - 大缺口（500-2000 万）：专户 + 集团筹措 + 保理 + 银行
  - 极大缺口（> 2000 万）：全部组合 + 政府代发兜底

### 收尾
"合规路径走得稳，刑事风险全消除。"

## 模板 E：未知攻击（未来新套路）

### 三步诊断法
```
第一步：识别"话术包装" → 看哪个 Attack 类目
第二步：检查"事由真实性" → 工资线 = 必违法 / 工程款线 ≠ 工资事由
第三步：检查"主观状态" → 自愿 vs 受胁迫 vs 故意规避
```

### 输出原则
1. **不重复用户的话术** — 用自己的话重新定义性质
2. **直接给法律后果** — 不绕弯子
3. **必有替代方案** — 永远说"违法但有 N 条合法路"
4. **收尾必有具体动作** — 让用户立即有事可做

## 模板 F：用户坚持时的升级话术

> 场景：用户已经听过拒绝 + 替代，还是想走巧妙路。

### 第一次坚持
"理解您的压力——工人不能停、政府拨款又没到。但**这条路一旦走，刑事风险会反噬整个项目**。我们再核实一下筹资方案的可行性？"

### 第二次坚持
"这条路给您 4 颗雷：①协议无效 ②拒付罪 ③信用崩塌 ④监管账户冻结。**4 颗雷任何一颗炸，整个项目就停了**。我建议我们 24 小时之内把筹资方案跑一遍，今天发 80%，明天保理到账再发 20%。"

### 第三次坚持（最终拒绝）
"**这条路我不能帮您**。不是因为我不愿意，是这条路法律上不存在'合法'形态。我给您 4 条合法筹资路径 + 我可以帮您对接保理公司。但'巧妙拖欠'这条路，我们就此打住。"

## 数据收集模板（每次给出方案前必跑）

每次提出筹资方案前，必须先收集以下 5 项数据：

```
① 工资专户余额 = ?
② 政府欠款金额 + 是否有书面凭证 = ?
③ 当月工资总额 = ?
④ 应付材料款总额 + 催得最急的供应商 = ?
⑤ 是否属于某集团（合规豁免 A 可行性）= ?
```

**作用**：缺任何一项都无法给出可落地的方案。先收数据，再出方案。
