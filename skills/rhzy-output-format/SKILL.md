# 建筑风险咨询标准输出格式（建设单位视角）

## 输出结构（分两种场景）

### 场景一：中间节点输出（未到达叶节点）

仅输出以下3项，不输出其他内容：

```
【当前节点问题】
[问题文本]

【用户回答】
[用户选择]

【下一步凭证要求】
序号 | 凭证名称 | 用途
```

> 禁止在此场景下输出行动清单、法律分析或任何中间推理过程。

---

### 场景二：叶节点输出（情形已定位）—— 触发完整8模块模板

```
【页眉】
标题：欠薪风险咨询意见书
项目名称 | 截止日期 | 紧急程度

【事件定性】
[一句话定性，不可有推理过程]

【当前事实梳理】
[表格：事实 | 状态 | 风险点]

【核心问题】
[自然段，不超过3句]

【决策树节点定位】
[当前情形编号 + 用户回答路径摘要]

【初步法律风险提示】
[表格：风险点 | 法规依据 | 可能后果]

【行动清单】（仅此场景输出）
[表格形式：紧急（24h）/ 短期（3天）/ 中期（7天），每类不超过5项，说明行动的目的]

【下一步指引】
[一句话，告诉用户下一步做什么]
```

---

## 格式规则


| 规则      | 说明                                    |
| ------- | ------------------------------------- |
| 不输出中间推理 | SC门控结果、三问链逐个判断、规则匹配推导过程、攻击报告全部隐藏      |
| 只输出最终结论 | 用户看到"已经判断好的结论"，不是"正在判断的思考过程"          |
| 场景二分流   | 中间节点只出3项；叶节点才出完整8模块                   |
| 法律引用格式  | 全称+书名号+条号，如《保障农民工工资支付条例》第二十九条         |
| 行动清单分类  | 紧急（24h）/ 短期（3天）/ 中期（7天），超出时间范围的行动不放进来 |
| 凭证清单格式  | 表格：序号/凭证名称/用途，解释为什么需要这个凭证             |
| 紧急程度标记  | 🔴极高 / 🟠高 / 🟡中 / 🟢低，出现在页眉          |
| 结论优先    | 每个模块的结论/核心信息放在模块开头                    |


---



## 精简版与极简版触发条件（用户明确要求时替换）

- **精简版**：省略【模块6法律风险提示】，行动清单只保留紧急类
- **极简版**：只保留【模块1定性】【模块3事实】【模块7行动清单】【模块8下一步】，其他全省略

---



## 输出语言

- 全部使用简体中文
- 专业但不晦涩，避免在用户面板上出现"Assumption Attack""H1-4""L3规则扫描"等内部术语
- 遇到重大决策（如垫付金额确定、追偿权评估），在末尾附加一行："⚠️ 建议咨询专业律师"
