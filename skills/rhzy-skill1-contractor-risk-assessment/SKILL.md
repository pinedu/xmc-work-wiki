# 施工单位企业风险评估

输入企业名称/统一社会信用代码，输出红/橙/黄/蓝四级风险等级 + 风险清单 + 建议措施。

## 风险评估指标体系 {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系} {#风险评估指标体系}

| 维度 | 关键指标 | 数据来源 | 权重 |
| --- | --- | --- | --- |
| 主体资质 | 资质等级及有效期、安全生产许可证状态 | 住建部四库一平台 | 15% |
| 司法风险 | 近3年诉讼数量及类型（被告/原告）、被执行金额、失信记录 | 裁判文书网、执行信息公开网 | 20% |
| 行政处罚 | 住建/安监/环保行政处罚次数及严重程度 | 本地住建信用平台 | 20% |
| 财务健康 | 注册资本实缴率、税务评级、欠税公告、动产抵押 | 国家企业信用信息公示系统 | 15% |
| 履约能力 | 在建项目数量与注册资本的比率、历史项目竣工验收率 | 住建监管平台 | 15% |
| 关联风险 | 法定代表人/股东关联企业风险、频繁变更法人或股东 | 工商数据 | 10% |
| 经营异常 | 是否列入经营异常名录、社保缴纳人数变化 | 国家企业信用信息公示系统 | 5% |

## 处理流水线 {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线} {#处理流水线}

```
输入：企业名称 / 统一社会信用代码
  ↓
[数据采集层] → 调用天眼查/企查查 API + 爬取公开政务数据
  ↓
[规则引擎层] → 硬规则（红线指标直接判高风险）
  例：失信被执行人 → 直接标红

  例：近1年行政处罚≥3次 → 高风险
  ↓
[LLM 分析层] → 对模糊信息做语义分析
  例：分析诉讼案件类型集中度（大量劳动争议=拖欠工资风险）

[输出层] → 风险等级（红/橙/黄/蓝）+ 风险清单 + 建议措施

| 红线条件 | 处置 |

本 skill 的采集层建议直接复用独立的 **rhzy-contractor-due-diligence** skill —— 它专门负责从 6 个公开政务数据源抓数据并落盘成结构化 JSON（schema 见下方），本 skill 只负责"拿到 JSON → 跑规则 → 输出评级"。

```
[rhzy-contractor-due-diligence: 采集层]
  ↓ 输出 ~/hermes/due-diligence/<公司>/<日期>/merged_<日期>.json

**触发模式**：当用户说"评估 [公司]""查一下 [公司] 靠不靠谱""做 due diligence"时，先调 due-diligence skill 拿 merged JSON，再回到本 skill 跑评级。**不要让本 skill 自己造采集逻辑**——采集/分析解耦后才能各自独立维护。

**输入 JSON schema 关键字段**（缺字段时本 skill 按剩余维度等比放大权重）：

| 字段 | 对应本 skill 维度 |
|---|---|
| `qualification.main_qualification` / `safety_license_expiry` | 主体资质 15% |
| `judicial.is_dishonesty` / `litigation_by_type` / `defendant_ratio` | 司法风险 20% |
| `administrative_penalty.items` / `guizhou_count_3y` | 行政处罚 20% |
| `finance.paid_in_capital` / `major_tax_violation` | 财务健康 15% |
| （S4 在建项目数 / 注册资本 比） | 履约能力 15% |
| `associated_risk.legal_rep_change_count_3y` | 关联风险 10% |
| `operation.in_business_exception_list` | 经营异常 5% |

**红线直判字段**（任何一条命中直接标红）：
- `judicial.is_dishonesty == true`
- `qualification.safety_license_expiry < today` 或 `main_qualification == null`
- `administrative_penalty` 近 1 年 ≥ 3 次
