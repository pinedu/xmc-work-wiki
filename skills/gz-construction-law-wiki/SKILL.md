以下任一情况立即加载：
- 用户问"按 XX 法 XX 条怎么规定"（条款级查询）
- 用户描述业务问题（工资拖欠/招标/消防/规划等）需找法律依据
- 撰写报告/合同/汇报材料需引用具体条款
- 与 rhzy- 系列 skill 联动做合规分析
- 校验 rhzy 项目当前做法是否符合法规

## 🛠️ 查询工具

本 skill 提供 3 个 Python 脚本（在 `scripts/` 目录），可单独调用：

### 1. `lookup_article.py` —— 按条款号查

```bash
python ~/.hermes/skills/rhzy/gz-construction-law-wiki/scripts/lookup_article.py \
  --law "保障农民工工资支付条例" --article "第二十四条"
```

输出：原文 + rhzy 项目对账清单

### 2. `search_keyword.py` —— 按关键词查

```bash
python ~/.hermes/skills/rhzy/gz-construction-law-wiki/scripts/search_keyword.py \
  --keyword "专户"
```

输出：所有提到该关键词的法规 + 上下文（前后 2 行）

### 3. `lookup_topic.py` —— 按业务主题查

```bash
python ~/.hermes/skills/rhzy/gz-construction-law-wiki/scripts/lookup_topic.py \
  --topic "农民工工资"
```

输出：相关条款表 + 法规名称 + 笔记路径

详见 `references/wage-law-supplement-2026-07-13.md`（本档新增的硬学习——必读）

**核心结论速记**：
- **入场资格**：国标允许"劳动合同或用工书面协议"（修订后），**贵州省标仍要求订立劳动合同**
- **劳资专管员**：国标"专（兼）职人员"，贵州省标"在项目部配备劳资专管员"
- **维权告示牌**：国标无规格，贵州省标 ≥ 1.5m×1m + 5 项必备内容
- **数据保存**：国标 ≥ 2 年，贵州省标 ≥ 3 年
- **登记时限**：国标无明文，贵州省标 10 个工作日内

**rhzy 项目实务判断铁律**：贵州境内项目，**省标严于国标时，按省标**；国标与省标一致时直接执行。

## ⚠️ 飞书渲染警示（必看）

> 本 skill 输出的法规条款引用、风险提示、对账清单等会**直接在飞书发给用户**。飞书 adapter 对 markdown 表格（`|` 表格行）**会强制降级为 text 纯文本渲染（"代码风格"）**。
>
> **铁律**：法规查询结果 / 风险对账清单 / 月度合规报告**禁用 ASCII 表格**（`|---|` 边框），改用：
> - **粗体小标题** + **emoji 标记**（🟢/🟡/🔴）
> - `- ` 列表 + `>` 引用块
> - 条款引用保持 `>` 块引用格式（这是飞书唯一保留的"代码"风格格式，且**与法规笔记本身一致**）
>
> 例外：上传给政府部门的 PDF / Word 公文**必须保留表格格式**（这是公文体例要求），但**对话中的预览版**必须用 emoji + 列表。
>
> **如果用户反馈"还是代码风格"** → 立刻 grep 当前回复中的 `|` 表格行，重写为列表+粗体。
