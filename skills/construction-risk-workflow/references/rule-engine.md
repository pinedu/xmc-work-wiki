# 建筑领域业务规则引擎

> 本文件是 `construction-risk-workflow` skill 的参考文档。规则簇1~8 共30余条 if-then 规则：A1~A22 欠薪、B1~B5 安全、C1~C3 质量、D1~D3 进度、E1~E3 合规、F1 主体一致性、G1~G2 技术、H1~H2 环境社会。Phase 1 规则扫描与 Phase 3 边界攻击时按规则编号检索。

---

本文档属于系统知识底座层，为主Agent的L3规则校验层提供"if-then"判定依据。
主Agent的L2开放推理层在生成策略时，**必须以本文档为护栏进行合规拦截**，但不得将规则命中当作策略生成的轨道。当情境超出规则覆盖范围时，主Agent必须标记"边界案例"，不得强行匹配。Sub-Agent的第二重校验（规则完整性）以本文档为对照标准。
> **关键原则**：规则引擎回答"什么条件下有什么风险"，不回答"应该怎么办"。策略路径由L2开放推理层独立生成，规则仅负责事后校验与拦截。
复杂规则（业务推理引擎）
这是第三层的核心战斗力——让本体像经验丰富的项目经理一样，自动识别风险、推导责任、发现矛盾。

│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │

│    风险等级：较大风险                                      │
│    责任主体：直接用工单位（劳务公司或施工单位）            │

│  规则A8：工资支付周期约定不明或超长 → 欠薪风险                │

│    推导出 "欠薪风险"                                       │
│    风险等级：一般风险（若周期>60天则升级为较大风险）       │
│    责任主体：合同签订双方（约定不清）                      │

┌─────────────────────────────────────────────────────────┐

│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │

│    推导出 "欠薪风险"（缺乏兜底保障机制）                   │
│    风险等级：较大风险                                      │
│    责任主体：施工单位（直接）、建设单位（连带督促责任）      │

│  规则A11：工资专户资金被挪用 → 欠薪风险                        │

│  条件：                                                   │

│    推导出 "欠薪风险"                                       │
│    风险等级：重大风险（恶意违规）                          │
│    责任主体：施工单位（挪用责任）、开户银行（监管失职）      │

┌─────────────────────────────────────────────────────────┐
│  规则A12：竣工结算久拖不决 → 欠薪风险                          │

│  条件：                                                   │

│    推导出 "欠薪风险"（结算不清导致工资尾款无法锁定和支付）  │
│    风险等级：较大风险                                      │
│    责任主体：建设单位（拖延结算）、施工单位（未积极主张）    │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  规则A13：工资支付周期异常延长 → 欠薪风险                     │
│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │
│    1. 某施工单位有连续的历史工资支付记录（管理信息）         │
│    2. 最近两次工资支付间隔超过45天                         │
│       或超过合同约定周期的1.5倍                            │
│    3. 无"不可抗力证明"或"双方协商延期"过程文件              │
│  结论：                                                   │
│    推导出 "欠薪风险"（支付节奏已实质性失控）               │
│    风险等级：较大风险                                      │
│    责任主体：施工单位                                      │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐

│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │
│    1. 某自然人（作业人员）考勤记录显示已连续停止出勤>15天   │

│    3. 工资表显示该自然人仍有"应付未付"余额                 │
│  结论：                                                   │
│    推导出 "欠薪风险"（退场即欠薪最高发场景）               │

│    责任主体：直接用工单位                                  │

┌─────────────────────────────────────────────────────────┐
│  规则A15：敏感时点未提前支付 → 欠薪风险（季节性预警）          │
│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │
│    1. 当前日期处于"春节前30天"或"开学前15天"（敏感时点）    │
│    2. 某施工单位存在"应付未付工资"记录（工资表已确认未发）  │
│    3. 无"节前工资支付计划"或计划未落实的过程文件            │
│  结论：                                                   │
│    推导出 "欠薪风险"（敏感时点极易触发群体性事件）         │
│    风险等级：重大风险（自动升级，不受其他条件限制）        │
│    责任主体：施工单位、建设单位                            │
│    触发动作：自动推送至监管单位（人社/住建）预警            │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  规则A16：考勤与现场人员严重不符 → 欠薪风险                   │
│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │
│    1. 某项目某月考勤系统记录的在场人数为 X                 │
│    2. 同一时间，现场安全检查记录/监理日志记录在场人数为 Y    │
│    3. |X-Y|/Y > 30%（差异超过30%，且无合理说明）          │
│  结论：                                                   │
│    推导出 "欠薪风险"                                       │
│    风险方向1：X>Y → 可能虚报考勤套取工资（冒领）           │
│    风险方向2：X<Y → 可能漏报人员逃避工资支付（漏发）       │
│    风险等级：较大风险                                      │
│    责任主体：施工单位、劳务公司                            │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  规则A17：工资表与专户流水不匹配 → 欠薪风险                   │
│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │
│    1. 某月工资表显示应发工资总额为 M（建筑信息）           │
│    2. 同一月份工资专户实际支付工资总额为 N（建筑信息）      │
│    3. |M-N|/M > 10%（差异超过10%，且无代发失败/退回说明）  │
│  结论：                                                   │
│    推导出 "欠薪风险"                                       │
│    风险方向1：M>N → 可能虚报工资表（套取资金）             │
│    风险方向2：M<N → 可能挪用专户资金用于非工资支出         │
│    风险等级：重大风险                                      │
│    责任主体：施工单位、劳务公司                            │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│  规则A18：社保缴纳与工资发放人数差异大 → 欠薪风险             │
│  ─────────────────────────────────────────────────────   │
│  条件：                                                   │

│    风险等级：较大风险                                      │
│    责任主体：施工单位、劳务公司                            │
│    关联风险：同步触发 "合规性风险"（未依法缴纳社保）       │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐

│  条件：                                                   │

│    责任主体：建设单位（首要）、施工单位（次要）              │

┌─────────────────────────────────────────────────────────┐
