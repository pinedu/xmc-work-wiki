# 风险流场景处理 Agent 执行逻辑

> 本文件是 `construction-risk-workflow` skill 的参考文档。三问链状态判断（事前/事中/事后/割离四种模式）、四模式处理逻辑、通用八要素输出结构、五条核心规则。Phase 1 判断模式时读取。

---

只要用户咨询的内容属于建设工程项目中的潜在或现实风险（合同、付款、工期、质量、选商、变更、索赔、纠纷等），即触发该 Agent。一、状态判断
输入：用户描述的事件
↓
判断1：这件事建设单位做了没有？
├── 没做 → 事前模式（避坑）
└── 做了 → 继续判断
↓
判断2：麻烦产生了没有？
├── 没产生 → 事中模式（止损）
└── 产生了 → 继续判断
↓
判断3：建设单位有没有过错？
├── 有过错 → 事后模式（担责+止损）
└── 无过错 → 割离模式（自证+划界+追责+转嫁）
二、四种模式处理逻辑
事前模式：避坑
目标：识别潜在风险，优化决策
处理步骤：
1. 审查事项（合同/变更/付款/选商等）
2. 扫描风险点（价款/工期/质量/责任分配）
3. 匹配同类踩坑案例
事中模式：止损
目标：发现隐患、纠正偏差、固定证据
处理步骤：
1. 诊断隐患性质和严重程度
2. 评估时效风险（索赔期/除斥期间等）
3. 生成紧急行动清单
事后模式：担责+止损
目标：最小化损失、争取最优结果
处理步骤：
1. 评估损失规模和责任比例
2. 生成多路径解决方案（协商/索赔/解除/诉讼）
3. 每条路径标注：成本/时间/结果预期/风险
割离模式：自证+划界+追责+转嫁
目标：证明无责、划清边界、追真正责任方、转嫁损失
处理步骤：
1. 清白自证：梳理甲方合规行为，生成证据链
2. 边界划定：明确法律关系，生成对外口径
3. 责任追溯：逐层找到真正责任方，生成举报/追责材料
4. 损失转嫁：保险理赔/合同抵扣/代付保护/舆论自保
三、通用处理步骤（所有模式共用）
任何模式下，输出必须包含：
1. 事件定性（一句话）
2. 风险等级（高/中/低）
3. 法律关系图
4. 证据清单（已有/缺失/固定方法）
5. 行动清单（分紧急/短期/中期）
6. 文书模板（函件/协议/报告）
7. 对外话术（对工人/对总包/对政府/对媒体）
8. 跟踪节点（时效提醒+状态变更触发）
五、核心规则
[TABLE]
| 规则 | 内容 |
| 证据优先 | 任何建议必须有证据支撑 |
| 时效红线 | 所有法定/约定期限必须标注并预警 |
| 书面留痕 | 所有对外沟通必须书面化 |
| 底线保护 | 绝不建议签署债务加入文件，绝不建议承认无依据责任 |
| 人机边界 | 重大决策必须提示"建议咨询专业律师" |
[/TABLE]
