# 情形执行动作（欠款转化）

> 本文件是 `construction-risk-workflow` skill 的参考文档。13种欠薪情形的“能不能转”判定、转化路径、专户硬边界、最终汇总表。Phase 2 四步判定时读取。

---

第一主干：施工单位未到合同约定进度
情形一：施工单位未到合同约定进度 → 产值未审，不付
能不能转：❌ 不能
为什么不能转： 产值未审意味着工程量尚未确定、工程款债权尚未形成。债权的产生以确定的给付内容为前提——金额不确定，就不存在“欠款”这个概念。甲方此时不付款系行使合同约定的先履行抗辩权，不构成欠款，无法转化。
甲方操作： 加速推进产值审核。审完后金额确定了，再按情形三或情形四操作。
情形二：施工单位未到合同约定进度 → 施工单位拖欠 → 甲方有钱未付
能不能转：⚠️ 有条件能转
转化路径：
路径一（施工单位配合）：
甲方将应付未付的工程款直接支付至施工单位账户。
同时与施工单位签订《委托付款协议》，约定“该笔款项优先用于发放农民工工资，乙方在收到款项后X个工作日内完成工资发放”。
该笔款项计入甲方已付工程款。
路径二（施工单位不配合或情况紧急）：
甲方直接垫付农民工工资（以未结清工程款为限），将工资发至工人银行卡。-
垫付后立即与施工单位签订《代付协议》，约定：“甲方代乙方垫付农民工工资XX元，该笔款项在甲乙双方工程款结算时予以抵扣，计入甲方已付工程款总额。”
垫付款通过结算抵扣转化为甲方已付工程款。
注意： 若甲方不存在任何到期应付工程款，且拖欠工资纯系施工单位自身原因导致，则甲方无垫付义务，不转化，直接发函免责即可。
第二主干：施工单位已达到合同约定进度
情形三：施工单位已达到合同约定进度 → 支付流程过长，支付延迟
能不能转：✅ 能转
转化路径：
甲方与施工单位签署《工程款支付确认书》或《延期付款协议》，明确欠付金额、支付期限、逾期利息。
协议中将该笔款项明确定性为“工程进度款欠款”。
甲方按协议约定期限付款。若届时仍未付，形成明确的工程款欠款债务。
情形四：施工单位已达到合同约定进度 → 产值已审，其他原因未付
能不能转：✅ 能转
转化路径：
以已审定的产值报告为基础，甲方与施工单位签署《欠款确认函》或《还款协议》。
协议明确：“甲方欠付乙方工程款XX元，该欠款为建设工程施工合同项下的工程款债权债务。”
约定“乙方应自行履行对农民工的工资支付义务，甲方不负有代付义务”——切断欠薪连带责任。
情形五：其他原因未付（汇总节点——不独立回答）
告知： 情形五是树状图中的汇总节点，不是一个可以独立回答“能不能转”的末端情形。用户说“我处于情形五”时，等于什么都没说——因为没有提供任何下级分支信息。
强制AI执行的判断流程（必须按顺序走完）：
第①问：甲方现在有没有钱付？
有钱 → 去第②问
没钱 → 去情形十三（末端），按情形十三的规则回答
第②问：项目是否实行分账支付（是否设有农民工工资专用账户）？
是（分账支付） → 去第③问
否（无分账支付） → 去第④问
第③问（分账支付）：专户里现在有没有余额
有余额 → 去情形六（末端），按情形六的规则回答
无余额 → 去第⑤问
第④问（无分账支付）：目前的欠薪状态是什么？
施工单位已经代发了工资 → 去情形十一（末端），按情形十一的规则回答
施工单位直接付了分包但工人还没拿到钱 → 去情形十二（末端），按情形十二的规则回答
什么都没有付，工人还在被欠薪 → 回到第①问（重新判断甲方有没有钱）
第⑤问（分账+专户无余额）：总包（施工单位）有没有自己的分账账户？
有（施工单位有分账） → 去第⑥问
无（施工单位无分账） → 去第⑦问
第⑥问（有分账）：甲方最近一期是否支付了“全额进度款”？
是（全额支付了进度款） → 去情形九（末端），按情形九的规则回答
否（未全额支付进度款） → 去情形七（末端），按情形七的规则回答
第⑦问（无分账）：总包（施工单位）的钱是怎么付出去的？
总包代发了工人工资 → 去情形十一（末端），按情形十一的规则回答
总包直接付给了分包单位 → 去情形十二（末端），按情形十二的规则回答
AI执行规则：
用户说“情形五”时，AI不得直接回答“能转/不能转/怎么转”。
AI必须按上述①②③④⑤⑥⑦的顺序逐一提问，直到走到末端情形（六、七、九、十一、十二、十三）。
走到末端情形后，按该情形的规则给出转化判断和操作路径。
第三主干：其他原因未付
第一大分支：甲方有钱 → 分账支付
情形六：分账支付 → 专户有余额
能不能转：⚠️ 部分能转
能转的部分： 甲方除专户资金外，尚欠付的其他工程款（如材料费、机械费、管理费、利润等）可以转化——单独签署《工程款欠款确认协议》。
不能转的部分：专户余额本身绝对不能转。
为什么专户余额不能转： 《保障农民工工资支付条例》第三十三条明确规定，专户资金不得因支付农民工工资之外的原因被查封、冻结、划拨。《暂行办法》第八条规定，开户银行不得将专户资金转入除农民工本人账户以外的账户。专户里的钱只能发工资，绝对不能用于抵扣其他欠款、不能借给甲方、不能转入其他账户。试图以任何形式挪用专户余额均属违法。
甲方操作： 发函给施工单位并抄送劳动监察：“我司已足额拨付人工费至专户，专户当前余额XX元。请贵司立即发放工资。如未及时发放导致的一切后果，由贵司自行承担。”
情形七：分账支付 → 专户无余额
能不能转：✅ 能转
转化路径：
甲方立即按合同约定标准，将应拨未拨的人工费用补拨至专户。
如合同未明确约定人工费具体比例，可参照项目所在地造价信息或行业惯例（通常为工程款的20%-25%）作为认定依据。在补拨或签署欠款协议时，应写明：“本次确认的欠款中，人工费为XX元，该金额系依据XX定额/XX号造价文件计算得出。”防止日后审计时对款项性质产生争议。
补拨后该笔款项计入甲方已付工程款。
若甲方无力全额补拨，则以未结清工程款为限先行垫付工资，垫付后签《代付协议》约定“在结算时予以抵扣”。
若仍有差额，就差额部分签署《工程款欠款确认协议》。
情形八：分账支付 → 施工单位有分账 → 专户有余额
能不能转：⚠️ 同情形六——专户余额不能转，其他工程款可转
操作同情形六。
情形九：分账支付 → 施工单位有分账 → 专户无余额 → 全额支付进度款
能不能转：✅ 能转
转化路径：
以合同约定的人工费用拨付标准为依据，核算本期应拨人工费与实际拨付至专户金额的差额。如合同未明确约定比例，参照造价信息或行业惯例（20%-25%）认定。
将差额单独补拨至专户，转账备注：“XX项目X月人工费用”。
补拨后该笔款项即为甲方已付工程款（人工费部分）。
若甲方无力补拨，就差额部分签署《工程款欠款确认协议》，并注明人工费认定依据。
注意： “全额支付进度款”不等于“足额拨付人工费”。人工费未单独进专户，即使进度款付了，仍构成人工费欠付。
情形十：分账支付 → 施工单位有分账 → 专户无余额 → 施工单位代发工资 → 专户有余额
能不能转：✅ 能转
转化路径：
施工单位已垫付工资，工人已拿到钱，欠薪事实已消除。
甲方与施工单位签署《代付确认协议》，约定：“贵司代为垫付的工资XX元，计入我司已付工程款，在后续结算中予以抵扣。”
如施工单位不配合签署协议，甲方单方发函确认同样有效。
垫付款通过抵扣转化为甲方已付工程款。
情形十一：分账支付 → 施工单位有分账 → 专户无余额 → 施工单位代发工资 → 专户无余额
能不能转：✅ 能转
转化路径：
施工单位已垫付工资，工人已拿到钱——欠薪事实已不存在，甲方刑事/行政风险已解除。
甲方与施工单位签署《代付确认协议》，约定：“贵司代为垫付的工资XX元，确认为我司欠付贵司的工程款，计入我司已付工程款总额，在结算时予以抵扣。”
该笔债务性质已从“欠薪”转化为“工程款欠款”。
闭环确认：甲方必须要求施工单位提供代发工资的银行流水凭证及工人签字的工资表，确认款项确实进入了工人账户。只有看到真金白银进了工人的口袋，甲方才能签署《代付确认协议》，将这笔款项确认为已付工程款。否则，施工单位声称“代发”但实际未发，甲方签了协议等于承认了一笔并未实际发生的付款，存在财务和法律风险。
第二大分支：甲方有钱 → 无分账支付
情形七（再次出现）：无分账支付 → 专户无余额
能不能转：✅ 能转
操作同情形七。
情形六（再次出现）：无分账支付 → 有分账支付 → 专户有余额
能不能转：⚠️ 同情形六——专户余额不能转，其他工程款可转
操作同情形六。
情形十二：无分账支付 → 专户无余额 → 施工单位直接支付分包单位
能不能转：分两种情况
情况A：分包单位已用该笔款项发放工人工资
能不能转：✅ 能转
转化路径：
总包已付给分包，工人已拿到钱，欠薪事实已消除。
闭环确认（关键） ：甲方不能仅凭“分包声称发了工资”就签署协议，必须要求总包提供分包单位向工人发放工资的银行流水凭证以及工人签字的工资表。只有确认款项确实进入了工人账户，甲方才能与总包签署《代付确认协议》。
签署《代付确认协议》，约定：“总包代付给分包的XX元，计入甲方欠付总包的工程款总额中，在结算时予以抵扣。”转化为甲方已付工程款。
情况B：分包单位拿到钱后未发放工人工资，工人仍在被拖欠
能不能转：❌ 不能直接转
为什么不能转： 工人没拿到钱，欠薪事实仍然存在，甲方法定垫付义务已被触发。-此时不能通过签协议把责任甩给总包或分包——政府查的是“工人有没有拿到钱”，不是“谁欠谁的钱”。
此时唯一正确操作： 甲方以未结清工程款为限先行垫付工人工资，垫付后按情形二路径——签《代付协议》约定“垫付款在结算时抵扣，计入已付工程款”——完成转化。
第三大分支：甲方没钱
情形十三：甲方没钱 → 从项目开工就未全额支付进度款 → 从未支付
能不能转：⚠️ 能转，但必须配合实际付款动作
为什么能转但必须配合付款： 甲方没钱不影响“工程款欠款”这个定性——只要施工单位干了活，甲方就欠工程款，签《欠款确认协议》在法律上完全有效。但政府关心的核心问题是“工人拿到钱没有”。如果工人没拿到钱，仅凭一纸协议无法对抗“恶意欠薪”指控。-
转化路径：
路径一（基础操作）：
与施工单位签署《工程款欠款确认协议》，明确：“甲方确认欠付乙方工程款总额为XX元，该欠款为建设工程施工合同项下的工程款债权债务。”
同步垫付部分工人工资（能垫多少垫多少），垫付后签《代付协议》约定“计入已付工程款，结算时抵扣”。
主动向劳动监察大队、住建局报告情况，出示《欠款确认协议》和垫付记录，请求将此事定性为“工程款民事纠纷”。
书面主张建设工程价款优先受偿权——进一步将双方关系锁定在“工程款债权债务”框架内。
路径二（现金流枯竭时的止损策略——以物抵债）：
如甲方确实没有任何现金流，可将项目未售出的房产、车位或设备，与施工单位签订《以房抵债协议》或《以物抵债协议》。
根据《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》，债务履行期限届满后达成的以物抵债协议，人民法院原则上应认可其效力。
关键操作要点：
抵债协议必须在债务金额已经确定（即已签署《欠款确认协议》）之后签订；
协议中必须明确抵债房产/资产的具体位置、面积、价格及抵偿金额；
协议签订后尽快办理物权转移的登记或交付手续。
完成物权转移登记或交付后，该笔工程款欠款即通过以物抵债方式得到清偿，同时有效化解刑事风险。
注意： 情形十三中，签协议+垫付部分工资+以物抵债（如适用）三者结合，转化效果最佳；只签协议不付钱，刑事风险不解除。
最终汇总表

| 情形 | 能不能转 | 核心原因 | 关键操作 |
| 情形一（产值未审） | ❌ 不能 | 金额未定，债权未形成 | 加速审产值 |
| 情形二（有钱未付） | ⚠️ 有条件 | 须先垫付或付款 | 垫付工资→签代付协议约定抵扣 |
| 情形三（流程过长） | ✅ 能 | 债务已成立 | 签支付确认书或延期协议 |
| 情形四（产值已审未付） | ✅ 能 | 债务已确定 | 签欠款确认函，切割工资责任 |
| 情形六（专户有余额） | ⚠️ 部分 | 专户余额法定不可动 | 专户不动；其他工程款可签确认书 |
| 情形七（专户无余额） | ✅ 能 | 人工费欠付 | 补拨人工费或垫付→抵扣 |
| 情形八（同六） | ⚠️ 部分 | 同六 | 同六 |
| 情形九（全额付进度款但专户无余额） | ✅ 能 | 人工费未单独拨付 | 核算差额→补拨或签确认书 |
| 情形十（总包代发后专户有余额） | ✅ 能 | 工资已发，欠薪事实消失 | 签代付确认协议→抵扣 |

| 情形十二（总包付分包） | 情况A✅；情况B❌ | 取决于工人是否拿到钱 | 核验流水+工资表；未发则甲方垫付 |
| 情形十三（甲方彻底没钱） | ⚠️ 能但须配合付款 | 协议有效但需实际动作 | 签欠款协议+垫付+以物抵债+报告政府 |
